ミナト

LLMを作れるようになりたいんです。でも、先輩に「まず線形代数と微積分と確率統計をやって、それから機械学習の本を3冊読め」って言われて……。正直、心が折れそうです。

ボンゴ先生

その先輩は正しい。正しいけど、順番が逆なんだ。泳ぎ方の本を10冊読んでからプールに入る人がいたら、溺れはしない。でも、たぶん一生泳げない。
この教室では、まずプールに飛び込む。浮き輪（コード）はこっちで用意する。水を飲んだら（エラーが出たら）、そのとき息つぎ（理論）を教える。それでいい。

ようこそ、つくってわかるLLMへ。ここは、ChatGPTやClaudeのような大規模言語モデル（Large Language Model、略して LLM）を、自分の手で動かし、作り、鍛え、世界に公開するところまで進む教科書です。

この章ではコードを書きません。15分だけ、地図を眺めましょう。登山だって、地図を見ずに登り始めると、山頂より先にコンビニに着いたりしますからね。

この教室の3つの約束

約束1：初日にLLMを動かす。 次の第1章で、無料のGoogle Colabを使って本物のLLMと会話します。所要時間は30分くらい。「理論を全部やってから実践」ではなく、実践の中で理論を学ぶのがこの教室のやり方です。

約束2：理論は必要になった瞬間に、必要なぶんだけ。 確率、対数、ベクトル、行列、微分……。どれもLLMの理解には欠かせません。でも、それらは「コードがそれを必要とした瞬間」に登場します。たとえば対数は「モデルの点数をつけたいのに、確率を掛け算すると小さすぎて0になっちゃう！」という困りごとと一緒にやってきます。困ってから習う道具は、よく手になじむんです。

約束3：お金は0円。 使うのは、Google Colab、Kaggle（どちらも無料でGPUが使えるサービス）、Hugging Face、GitHubだけ。高いGPUも、有料のAPIもいりません。それでも、ゼロからのGPT作り、ファインチューニング、公開まで、本格的にできます。

ボンゴ先生

ちなみに私の名前の「ボンゴ」は太鼓のこと。ボンゴを叩くのが大好きな物理学者がいてね、リチャード・ファインマンという。「自分で作れないものは、理解していない」と黒板に書き残した人だ。この教室のモットーもそれ。……あ、私は彼の親戚でも何でもない。ただのファンだ。

最後にできるようになること

この教科書を最後まで進めると、あなたは次のことが自分の手でできるようになります。「知っている」ではなく「できる」です。

  1. 公開されているLLMを、無料のGPUで動かして会話させる（第1章）
  2. 文章をトークンという数字に変え、モデルが次の言葉を確率で選ぶ様子を観察する（第2〜3章）
  3. 夏目漱石の小説で、ゼロから言語モデルを作る（第4〜10章）
  4. GPTの心臓部であるTransformerを一行ずつ自分で書いて、GPUで学習させる（第11〜13章）
  5. トークナイザーを自作し、自分のコードに本物のGPT-2の重みを読み込んで動かす（第14〜16章）
  6. 公開モデルをファインチューニング（追加学習）し、LoRAで省メモリに鍛え、正しく評価する（第17〜20章）
  7. 資料を検索して答えるRAG、人の好みを教えるDPO、道具を使うエージェントを作る（第21〜23章）
  8. 作ったLLMをブラウザで動くWebページとして公開する（第24章。HTMLとCSSの知識がここで効いてきます！）
  9. 最新の論文の部品（RoPE、MoEなど）を自分のモデルに移植し、卒業制作をまとめる（第25〜26章）

箱の見方

この教科書には、いろいろな箱が出てきます。見た目で役割が分かるようにしてあります。

理論の小部屋：これが理論の小部屋

黒板の色をした箱です。コードを動かして「なんでこうなるの？」と思った、まさにそのときに出てきます。数式も出ますが、必ず「言葉での説明」と「確かめるコード」がセットです。

やってみよう：数字を変えてみよう

手を動かす実験です。「予想する → 実行する → 予想と比べる」の順番でやるのがコツ。予想が外れたら大当たり。そこに学びがあります。

つまずき注意：よくあるエラー

みんながつまずく場所に、先回りして立っている看板です。エラーが出たら、まずこの箱を探してください。

基本情報とつながる

基本情報技術者試験で習う内容（2進数、文字コード、浮動小数点、アルゴリズムなど）が、LLMのどこで使われているかを教えてくれる箱です。試験勉強が「ただの暗記」から「LLMの部品」に変わります。

挫折しないための3つのルール

LLMの勉強で人が挫折する理由は、だいたい3つです。「エラーで止まる」「理論の壁で止まる」「成果が見えなくて止まる」。それぞれに作戦を用意しました。

ルール1：20分ルール。 同じエラーで20分止まったら、次の順番で助けを呼びます。

  1. その章の「つまずき注意」の箱を読む
  2. 付録E エラー辞典でエラーメッセージを検索する
  3. 生成AI（ChatGPT・Claude・Geminiなど、無料版でOK）に、次のテンプレートで質問する
  4. それでもダメなら、印を付けて次の節へ進む（後で戻ればいい）
テキスト
Google Colabで「つくってわかるLLM」第◯章のコードを実行したら、エラーが出ました。
初心者なので、原因と直し方を順番に教えてください。

【実行したコード】
（ここにセルの中身を貼る）

【エラーメッセージ】
（赤い文字の最後の数行を貼る）

【試したこと】
（ランタイムを再起動した、など）

ルール2：6割わかったら次へ。 1回読んで100%理解できる人はいません。ファインマンだって、たぶん無理です（本人に聞いたことはありませんが）。この教科書は、大事な考え方が後の章で何度も形を変えて出てくるように作ってあります。2周目で分かることも多いのです。

ルール3：小さく記録する。 各章の終わりにチェックリストと「この章をクリアした！」ボタンがあります。押すと目次にチェックが付きます。小さな達成感は、思っているより強いエンジンになります。

数学について、正直な話

この教科書は、高校数学を前提にしません。必要な数学は、すべてその場で、言葉と絵とコードで説明します。登場する主な道具はこんな感じです。
