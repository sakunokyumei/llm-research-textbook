ミナト

LLMを自分で作って、ゆくゆくは研究もできるようになりたいんです。でも、コードも数学もいきなり難しくて「読んだのに何も分からない……」とならないか不安で。

ボンゴ先生

とても正直で大事な不安だ。実際、この教科書の最初の版を読んでくれた学習者からも「第1部の時点で数式もコードも難しかった」「解説を読むと分かった気になるけど、本当に理解できたか確かめる問題が足りない」という貴重な声をもらった。
だから、この教科書は「なぜその計算をするのか」「このPythonコードは何を受け取って何を返すのか」を省略せず、途中で何度も確認問題と復習を挟む設計に作り直したんだ。ゴールの高さは1ミリも下げず、登る階段だけを細かくしたよ。

ようこそ、つくってわかるLLMへ。ここは、ChatGPTやClaudeのような大規模言語モデル（Large Language Model、略して LLM）を、自分の手で動かし、内部の数式とコードを理解し、作り、鍛え、評価し、研究の入口まで進む教科書です。

この章ではコードを書きません。15分だけ、地図と学び方を確認しましょう。

この教室の3つの約束

約束1：初日からLLMを動かしながら、仕組みの「なぜ」を省略しない。 次の第1章で、無料のGoogle Colabを使って本物のLLMと会話します。ただし「呪文だと思って貼り付けて終わり」にはしません。コードの前に最小限の短いコードでPythonやライブラリの動きを確かめ、入力・中間値・出力・データ型を1つずつ確認してから本物を動かします。

約束2：数学は記号の読み方と「なぜ必要か」から説明する。 ∑\sum∑（シグマ）や exe^xex、log⁡\loglog、行列、微分……。記号を暗記している前提にはしません。「どんな困りごとを解決したいか → 素朴な方法ではなぜダメか → 小さな数字で手計算 → 数式にまとめる → Pythonで検証 → 問題で確認」の順番で進みます。

約束3：基本0円で学べ、読了だけでなく「できる」を確かめる。 使うのはGoogle Colab・Kaggle・Hugging Face・GitHubの無料枠だけです（無料GPUの混雑や利用枠は時期により変動するため、GPUが使えない日はCPU実行やKaggleへの切替で進められます → 付録A）。そして「解説を読んだだけ」でクリアとはせず、途中の確認問題・類題・自力実装・時間を空けた復習で定着を確かめます。

ボンゴ先生

ちなみに私の名前の「ボンゴ」は太鼓のこと。ボンゴを愛した物理学者リチャード・ファインマンが黒板に書き残した言葉 “What I cannot create, I do not understand.”（自分で作れないものは、理解していない）が、この教室のモットーだ。読んで分かった気にならず、小さな部品を自分の手で作りながら確かめよう。

2つの学習コース（最終到達目標は同じ）

人によって、Pythonや数学の得意・不得意はまったく違います。たとえば「Pythonの基本文法や簡単なアルゴリズムは書けるけれど、数学記号やPyTorchの書き方にはまだ慣れていない」という人も多いはずです。そこで、この教科書では2つのコースを用意しました。

コース 向いている人 画面での違い 最終到達目標
じっくり理解コース（初期設定） 数学記号やPyTorch特有の書き方を基礎から丁寧に学びたい人 「基礎の補足」箱が最初から開いて表示され、基礎確認問題も含めて階段を細かく進む GPT自作・LoRA・RAG・DPO・評価・研究
標準コース すでに知っている基礎は読み飛ばし、要点と演習に集中したい人 「基礎の補足」箱が折りたたみ表示になり、必要なものだけ開ける 同じ（GPT自作・LoRA・RAG・DPO・評価・研究）

どちらのコースも、左のサイドバー（または学習状況・復習ページ）からいつでも切り替えられます。

最後にできるようになること

「用語を聞いたことがある」ではなく、次の10個を自分の力でできるようになることが目標です。

  1. 数式に登場する記号の読み方と意味を説明できる
  2. なぜその式が必要なのか、どんな発想で導かれるのかを説明できる
  3. Python・PyTorchコードの各処理について、入力・出力・処理目的を説明できる
  4. コードを実行する前に出力やテンソルの形（shape）を予測できる
  5. 既存コードの数値や条件を書き換えて挙動を実験・検証できる
  6. 小さな機能（トークナイザー、softmax、勾配降下、Attentionなど）を何も見ずに自力実装できる
  7. LLMの内部構造を数式とコードの両面から説明できる
  8. TransformerとGPTを自作し、夏目漱石の文章で学習できる（第11〜13章）
  9. LoRA、RAG、DPO、モデル評価、Web公開を実践できる（第17〜24章）
  10. 論文を読み、仮説を立て、実験し、結果を評価できる（第25〜26章）

箱の見方と学習コース

この教科書には役割ごとの箱があります。

基礎の補足「基礎の補足」箱（じっくり理解コースでは自動で開きます）

数学記号の読み方や、Python・PyTorchの文法（メソッド、辞書展開 **kwargs、内包表記など）を、小さな具体例でかみ砕いて説明する箱です。すでに分かっているときはクリックで閉じられます（標準コースでは最初から閉じています）。

これまでの復習とつながり：「これまでの復習とつながり」箱

前の章で学んだ内容が、今の章のどこで使われているかを結ぶ箱です。「確率 → softmax → Attention → Transformer」のように知識をつなげて定着させます。

理論の小部屋：理論の小部屋

黒板の色をした箱です。数式やアルゴリズムの「なぜそうするのか」を、小さな具体例・手計算・コード検証とセットで解説します。

やってみよう：やってみよう

コードの数字や条件を書き換えて実験する箱です。「予想する → 実行する → 比べる」の順で試すと理解が深まります。

つまずき注意：つまずき注意

エラーが出やすい場所や、誤解しやすい落とし穴を先回りして解説する箱です。

重要な概念を1つ学んだら、章の途中でもすぐに確認問題が出てきます。まず自分で考えて答えを選んでみてください。

理解度の7段階と間隔復習

この教科書では、単純な「読んだ／読んでいない」だけでなく、学習状況を次の7段階で記録します。

  1. 未学習
  2. 説明を読んだ（章を読み進めた／読了チェックを押した）
  3. 基礎問題を解いた（Lv.1 確認・Lv.2 理解の問題を解いた）
  4. 応用問題を解いた（Lv.3 応用・Lv.5 発展の問題を解いた）
  5. 自力実装を完了した（Lv.4 実装課題のColab検算テストを通過した）
  6. 復習が必要（誤答があった、または復習予定日が到来した）
  7. 復習で再確認できた（時間を空けて、別の条件の類題で正解できた）

1回正解しただけで「完全理解」とは表示しません。丸暗記を防ぐため、同じ概念に対して数字・文章・コードを変えた類題を用意しています。

  • 間違えたとき：単なる「不正解」ではなく、どこが間違っているか・正しい考え方・途中計算・該当する節へのリンク・別の具体例を表示し、復習間隔を1日に短くします。
  • 正解が続いたとき：初期設定では 1日後 → 3日後 → 7日後 → 14日後 → 30日後 と復習間隔を少しずつ延ばします（これは一般的な初期目安であり、唯一最適な間隔ではありません）。
  • 自由記述・実装課題：自動採点できない課題では「検証できる範囲」を明示し、確認観点やColab用の assert 検算テストを添えています。

学習履歴の保存と注意点

学習履歴（問題ごとの解答履歴・正誤・最終学習日・苦手な概念・復習予定・コース設定）は、このブラウザの中（localStorage）だけに保存されます。サーバーへの送信や有料アカウントは一切不要です。

  • 保存容量：ブラウザごとに通常5MB程度の上限がありますが、学習履歴は数十KB以内で収まります。
  • 端末・ブラウザ変更時の制約：別のPCや別ブラウザには自動同期されません。またブラウザのサイトデータを消去すると履歴も消えます。引き継ぎやバックアップには学習状況・復習ページのJSON保存／復元を使ってください。

挫折しないための3つのルール

  1. 20分ルール：同じエラーで20分止まったら、「つまずき注意」→ 付録E エラー辞典 → 生成AIに質問（付録H 挫折しない作戦帳に質問テンプレートあり）の順で助けを呼ぶ。
  2. 分かった気にならないための確認：解説を読んだら、必ずその直後の確認問題を自分の頭で解く。間違えたら「どこで思い違いをしたか」を確認して類題に再挑戦する。
  3. 小さく記録し、復習で戻ってくる：学習状況・復習ページを開けば「今日何を復習すべきか」「何が苦手か」がひと目で分かります。
