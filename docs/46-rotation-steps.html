直角の回転から、位置の差へ進む

図を描く10〜15分、表を埋める10〜20分、コードの実行15〜30分を別の回へ分けます。横がx、縦がyの座標から始めます。

1．十字の図で点を回す

反時計回りに90度なら(x,y)→(−y,x)。点(2,1)なら(−1,2)。平方した長さは5のままです。180度なら(−x,−y)です。

2．角度の単位と二つの数

ラジアンは角度の単位。半径1の円の弧の長さで角度を表し、一周2π、半周π、直角π/2です。πは円周と直径の比で約3.14159。cosとsinは、この円の点の横座標と縦座標です。

角度 cos sin 入力(2,1)を回した点
0 1 0 (2,1)
π/2 0 1 (−1,2)
π −1 0 (−2,−1)

一般のθでは(x cosθ−y sinθ, x sinθ+y cosθ)。90度の行を代入して、最初の図へ戻ることを確かめます。

3．二点を同じだけ回す

q=(1,0)、k=(0,1)は内積0。両方を90度回すとq=(0,1)、k=(−1,0)で内積も0。片方だけ回す場合は、相対的な角度が変わり内積も変わり得ます。

RoPEは、QとKの数の対を位置に応じて回す方法です。Qの位置m、Kの位置nなら、本編の式では差(n−m)θが現れます。m=2,n=5なら3θ。位置の番号が5だけで決まるわけではありません。

自力の問題： (3,2)の90度回転は(−2,3)、長さの二乗は前後とも13。Qの位置4、Kの位置10なら角度差6θです。
