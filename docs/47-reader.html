47 状態空間モデルと拡散言語モデル：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

過去を全部持つ必要がある？

会議の議事録を毎回すべて読み返す方法と、要点をメモに更新し続ける方法を比べます。Attentionは過去の位置へ直接アクセスできます。一方、再帰的なモデルは状態という一定の大きさのメモを更新します。メモは安く持てますが、後で必要になる情報を捨ててしまうかもしれません。

状態空間モデル（SSM）の最も単純な離散形は h_t = A h_(t−1) + B x_t, y_t = C h_t。hは状態、xは入力、yは出力です。Aは過去をどう残すか、Bは新しい入力をどう加えるか、Cは状態から何を読むかを表します。hが二成分ならAは2×2行列です。これはMambaそのものではなく、出発点となる仕組みです。

小さな状態を計算する

A=0.5、B=C=1、h₀=0、入力が2,0,4なら状態は2,1,4.5。過去の2は二回半減して0.5残ります。Aを固定すると、重要な語も不要な語も同じ規則で忘れます。Mambaでは入力に応じてSSMの一部のパラメータを変え、情報を選択します。高速なscan実装も核心です。単純なPythonループだけで同じ速度特性が得られるとは限りません。Mamba原論文

state = 0.0
for value in [2, 0, 4]:
    state = 0.5 * state + value
    print(state)

左から書く以外の生成

次に、計算の構造とは別の問いを考えます。文章は必ず左から一語ずつ生成する必要があるでしょうか。拡散言語モデルには、文字列の一部をmaskで隠す過程を学び、maskを徐々に埋める方法があります。LLaDAはTransformerを使ったmask予測を、拡散の生成・学習の枠組みに置きます。「拡散だからTransformerではない」という分類は誤りです。LLaDA原論文

たとえば「私は [MASK] を [MASK]」を埋め、確信の低い位置を更新します。ただし実際の学習損失にはmask率に応じた重み付けがあり、BERT式の穴埋めをそのまま自由生成へ転用する説明では足りません。生成ステップ数を減らすと品質が変わるため、同じ出力長・ハードウェア・品質水準で遅延を比べます。

1・忘れる速さ

A=0.8、B=1、h₀=0、入力1,0,0を計算してください。

解答と考え方を読む

h₁=1、h₂=0.8、h₃=0.64。初期の寄与はAの累乗で減ります。

2・固定容量の代償

状態が一定サイズなら、任意長の文章を完全に復元できますか。

解答と考え方を読む

有限精度で表現できる状態数には限りがあります。任意の文章を損失なく保存する保証はありません。課題に必要な情報を残せるかを測ります。

3・速度比較

拡散モデルが8回、自己回帰モデルが128回ネットワークを呼びました。16倍高速ですか。

解答と考え方を読む

断定できません。各回で計算する位置数、cache、並列性、メモリ転送が異なります。実測の壁時計時間と品質を揃えます。

4・研究への一歩

copy課題でSSMとAttentionを比較する独立変数と従属変数を挙げてください。

解答と考え方を読む

独立変数は記憶方式と距離。従属変数はcopy正解率、時間、最大メモリなど。学習例数・seed・パラメータ数または計算予算を管理します。公平性の基準を先に決めます。
