11-6 動いたことは、正しいことか

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の6/10ページ。

誤った平均を返すプログラムも、エラーを出さずに動くことがあります。そこで「この入力にはこの答えになるはず」という小さな約束を作り、実際の結果と比べます。これをテストと呼びます。

コードを読むための道具を三つ確認します。len([2,4,6])は要素の個数3、sum([2,4,6])は合計12、abs(-3)は符号を除いた大きさ3です。数学の絶対値の復習は第3章、繰り返して足す方法は第9章へ戻れます。下の平均は「合計÷個数」です。

def mean(values):
    if len(values) == 0:
        raise ValueError("空の並びの平均は求めません")
    return sum(values) / len(values)

assert mean([2, 4, 6]) == 4
assert mean([7]) == 7
assert abs(mean([0.1, 0.2]) - 0.15) < 1e-12
print("checks passed")

assertは条件が偽なら止まって知らせます。最後の比較だけ誤差の許容幅を設けたのは、小数の計算が有限精度だからです。許容誤差を大きくしすぎると本当の間違いを見逃します。
