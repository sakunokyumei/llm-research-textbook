19 積分と連続的な量：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

速度から距離へ戻る

一定の速度で2時間進むなら、距離は速度×時間です。速度が変わる場合はどうでしょう。時間を細かい区間に分け、その区間ではほぼ一定とみなして距離を計算し、足し合わせます。分け方を細かくした極限が積分です。

速度v(t)=tで0から2まで進む模型を考えます。幅1の二区間を左端の速度で近似すると0×1+1×1=1。右端なら1×1+2×1=3。幅を細かくすると、両方とも速度のグラフの下にある三角形の面積2へ近づきます。

記号では∫₀² t dt=2と書きます。0と2は範囲、tは足し合わせる量、dtはtを細かく区切って積み上げることを表します。積分は符号付きの蓄積なので、関数が負の区間では負に寄与します。単に常に正の図形の面積だと考えると誤ります。

微分との関係

微分するとtになる関数はt²/2です。微積分の基本定理が使える条件では、区間の積分は原始関数Fの差F(b)−F(a)で求められます。今回は2²/2−0²/2=2です。不定積分には定数Cが付きます。定数を微分すると0なので、微分だけでは元の定数が分からないからです。

この関係により、変化率を知れば蓄積を求め、蓄積の変化を調べれば元の量へ戻れます。後の確率の章でも使います。「解析的に求める」は公式や式の変形で答えを表すこと、「数値積分」は区間を分けた計算で近似することです。「標本」は調べる全体から取り出した一部で、第22章で学びます。

足した値を残す一行

買い物の合計へ次の品物の値段を足すのと同じです。area += t * widthは、今回の小数の変数では area = area + t * width と同じ計算結果になります。+=を加算代入と呼びます。後の回帰で使う w -= change は今回の数値なら w = w - change です。配列やリストでは、その物自体を書き換える場合があり、参照先への影響まで常に同じとは限りません。Pythonの仕様も確認できます。代入の復習は第8章、合計の繰り返しは第9章へ。

n=2なら幅は1、中央の時刻は0.5と1.5です。

区間 中央t 足す距離t×幅 合計area
0〜1 0.5 0.5 0.5
1〜2 1.5 1.5 2.0

次のコードのnを2に変え、各回のareaを表示して表と比べてください。

n = 1000
width = 2.0 / n
area = 0.0
for i in range(n):
    t = (i + 0.5) * width
    area += t * width
print(area)

各区間の中央の値を使っています。結果は丸め誤差の範囲で2です。この例の関数は直線なので中央の長方形による近似が特にうまくいきます。どんな曲線にも有限のnで正確という意味ではありません。

密度を面積へ変える

確率は起こりやすさを0〜1で表す数でした。ここでは「0〜2の間で、同じ幅の区間は同じ起こりやすさになるくじ」を考えます。このように偏りなく広がる分布を一様分布と呼びます。分布は値がどう現れるかを表すものです。連続値では区間の幅を限りなく細かくできるため、一点ではなく範囲に入る確率を測ります。

密度は「横の幅を掛けると、その区間の確率になる高さ」です。一様分布では高さが一定で、0〜2の外では0です。全体の確率1を幅2へ広げるので、高さは1÷2=1/2。0.5〜1.5は幅1なので確率は1×1/2=1/2です。一般に高さが変わる場合は、積分の導入で細かい面積を足します。

たとえば幅0.5へ全確率1を広げれば高さは2です。密度が1を超えても、面積が1なら確率の規則に反しません。詳しい確率の数え方は第20章へ、分布と平均は第21章へ進みます。

1・短い記法を展開する

area=0.5、t=1.5、width=1のとき area += t * width を普通の代入で書き、更新後の値を答えてください。

解答と考え方を読む

area = area + t * widthです。0.5+1.5×1=2.0になります。

次へ進む前に

積分の記号を「どの範囲の何を足すか」と説明し、上の二区間の表を作り、一様分布の幅×高さを計算できれば次へ進めます。一般の分布は後の章で広げます。コードだけで止まったら、まずn=2の通常代入 area = area + t * width に戻してください。

追加の確認問題

2・一定量の蓄積

速度3m/sで4秒進む距離を、積分の考え方で説明してください。

解答と考え方を読む

幅4、高さ3の長方形に対応し、3×4=12mです。単位もm/s×s=mとなります。

3・原始関数

∫₀³ 2t dtを求めてください。

解答と考え方を読む

原始関数はt²なので3²−0²=9です。

4・符号

−1から1までf(x)=xを積分すると何になりますか。

解答と考え方を読む

負の三角形と正の三角形の寄与が打ち消し合い0です。図形の面積の合計なら1ですが、符号付き積分とは別です。

5・密度と確率

0から0.5の一様分布の密度はいくつですか。1を超えてもよい理由を説明してください。

解答と考え方を読む

密度は2です。幅0.5×高さ2=1なので全確率は1。密度は点の確率ではなく、範囲へ積分して確率にします。
