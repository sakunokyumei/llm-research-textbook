14 ベクトルと内積：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

一つの数では表せないもの

果物を「重さ150g、甘さ8点」の二つの数で表すとします。順序を決めた数の並び(150,8)をベクトルと呼びます。二つの成分があるので二次元です。成分が増えても基本は同じです。LLMも単語や文章を多数の数の並びとして扱いますが、一つ一つの成分に「甘さ」のような人間の意味が付いているとは限りません。

ベクトルの足し算は対応する成分を足します。(1,2)+(3,4)=(4,6)。数を掛けるスカラー倍では全成分へ掛け、2(1,2)=(2,4)。スカラーとは、この文脈では並びではない一つの数です。

内積は、対応を掛けて足す

単価が(100,200)、購入数が(2,3)なら合計金額は100×2+200×3=800円です。この計算が内積です。x=(x₁,…,x_d)、w=(w₁,…,w_d)ならx·w=Σᵢ xᵢwᵢ。次元が同じベクトル同士を入力して、一つの数を出します。

直角は二つの方向が90度で交わること、直角三角形は一つの角が直角の三角形です。その直角の向かい側が斜辺。二つの直角をはさむ辺が3と4なら、斜辺の長さは√(3²+4²)=5。この関係をピタゴラスの定理と呼びます。

ユークリッドノルムはベクトルの長さを表し、||x||₂=√(Σᵢxᵢ²)です。(3,4)なら√(9+16)=5。二次元では直角三角形の斜辺を求めるピタゴラスの定理と一致します。

大きさと方向を分ける

(1,0)と(2,0)は長さが違いますが向きは同じです。二つのベクトルの内積が0のとき直交すると呼びます。ゼロでない二次元の方向なら、互いに直角という意味です。(1,0)と(0,1)は内積0で、横と縦の関係です。直交へ戻れます。0でない二つのベクトルについて、コサイン類似度は(x·y)/(||x||₂||y||₂)。同じ向きは1、直交する向きは0、逆向きは−1です。どちらかがゼロベクトルなら分母が0になり、この式のままでは定義できません。

言葉を数の並びで表したものを埋め込みと呼びます。検索では方向の似た埋め込みを探すことがあります。ただし類似度が高いことは、二つの文章が事実として同じだという保証ではありません。また重さと甘さのように単位の違う値をそのまま入れると、大きな尺度の成分が結果を支配します。

手計算を、一行ずつコードにする

Σや平方根が読めないときは第6章の記号と第4章の平方根へ、for文なら第9章へ戻れます。まず短縮した書き方を使わず、対応する位置の値を掛けて足します。

位置 xの値 yの値 掛けた値 ここまでの合計
0 3 4 12 12
1 4 3 12 24 
import math
x = [3, 4]
y = [4, 3]
if len(x) != len(y):
    raise ValueError("二つの並びの長さをそろえてください")
dot = 0
square_x = 0
square_y = 0
for i in range(len(x)):
    dot = dot + x[i] * y[i]
    square_x = square_x + x[i] * x[i]
    square_y = square_y + y[i] * y[i]
nx = math.sqrt(square_x)
ny = math.sqrt(square_y)
if nx == 0 or ny == 0:
    raise ValueError("長さ0のベクトルの類似度はこの式では計算できません")
print(dot, nx, dot / (nx * ny))

mathは数学の道具をまとめたモジュール、math.sqrt(25)は25の平方根5を返す操作です。len(x)は要素数2なので、range(len(x))は位置0、1を順に使います。!=は「等しくない」、orは「どちらか一方でも条件が成り立つ」を表します。最後の出力は 24 5.0 0.96。小数表記の5.0も値は5です。

1・途中の値を追う

上のコードでi=0の一回目が終わった直後、dot、square_x、square_yはいくつですか。

解答と考え方を読む

12、9、16です。二回目でそれぞれ24、25、25になります。完成した出力だけでなく途中も手計算と比べます。

短い書き方へ進む橋（今日は保留してよい）

二つの並びを対応させるzip(x,y)は、この例では(3,4)、(4,3)という組を順に渡します。a,b = (3,4)はaへ3、bへ4を割り当てる書き方です。これを組の展開（アンパック）と呼びます。次のfor文は組を一つずつ受け取り、その場でaとbに分けます。

x = [3, 4]
y = [4, 3]
products = []
for a, b in zip(x, y):
    products.append(a * b)
print(products)
print(sum(products))

出力は [12, 12] と24。appendは末尾への追加、sumは合計です。この「組を取り出す→掛ける→追加する」を、[a * b for a, b in zip(x, y)]とも書けます。リストを作るこの書き方が内包表記です。

丸括弧の (a * b for a, b in zip(x, y)) は、全結果のリストを先に作らず、求められた順に値を渡す生成式です。sumへ渡すと、それらを足します。次の二通りを比べてください。

x = [3, 4]
y = [4, 3]
products = [a * b for a, b in zip(x, y)]
print(sum(products))
print(sum(a * b for a, b in zip(x, y)))

どちらも24です。sumの唯一の引数が生成式なら、その生成式用の括弧を一組省略できます。zipは標準では短い並びの終わりで止まるため、最初のコードの長さ確認は短縮版でも必要です。短い書き方を暗記するより、普通のfor文へ戻して説明できることを優先しましょう。

2・通常のforへ戻す

sum(a * a for a in [1,2,3])を、合計を0から始めるfor文で書き直してください。

解答と考え方を読む

合計を0にし、1、2、3について順に total = total + a * a を実行します。合計は1、5、14と変わります。二乗してから足す順序が同じか確認してください。

Pythonのデータ構造と内包表記、生成式、sumとzipが仕様の参照先です。

3・ベクトルの演算

(2,−1)+(3,4)と、−2(2,−1)を求めてください。

解答と考え方を読む

(5,3)と(−4,2)です。符号も各成分へ作用します。

4・内積

(1,2,3)と(4,0,−1)の内積を求めてください。

解答と考え方を読む

1×4+2×0+3×(−1)=1。結果はベクトルではなくスカラーです。

5・ノルム

(0,−5)と(1,2,2)のノルムを求めてください。

解答と考え方を読む

5と√(1+4+4)=3です。長さは非負です。

6・直交

(1,1)と(1,−1)のコサイン類似度を計算してください。

解答と考え方を読む

内積1−1=0、両方の長さ√2。したがって類似度は0です。

7・尺度

ベクトル(1,2)を正の数10倍したとき、元のベクトルとのコサイン類似度はいくつですか。

解答と考え方を読む

1です。大きさは10倍ですが向きは同じです。内積だけなら大きさにも影響されます。

8・実装の条件

内積を計算する関数に[1,2]と[3]を渡したとき、zipだけでは何が起きますか。

解答と考え方を読む

最初の組だけを使って3を返してしまいます。数学上の同じ次元という条件を満たさない入力なので、長さの確認でエラーにするのが適切です。

到達課題と出典

基本の到達目標は、[3,4]と[4,3]の内積24、長さ5、類似度0.96を手計算とコードで一致させ、長さの不一致とゼロの入力で止める理由を説明することです。短縮構文は保留しても、この基本課題を確認できます。

発展課題は三つの架空の文書ベクトルと一つの検索ベクトルで類似度を計算することです。まず各値を紙に書いて大きい順に並べれば十分です。並べ替えの新しいPython構文はまだ必要ありません。ゼロベクトルは今回のコードと同じくエラーにする、と決めて記録してください。MIT 18.06 Linear Algebra の内積・直交の考えにつながります。
