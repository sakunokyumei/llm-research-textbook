08 Pythonで、最初の計算を動かす：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

同じ計算を何度も頼む

1000件の正解率を毎日計算するなら、電卓へ同じ手順を入力するのは大変です。コンピュータへ「この順に計算して」と渡す文章がプログラムです。ここではPythonという言語で書きます。初めは高度な開発環境は不要です。

ターミナルは、文字で操作を頼むアプリです。入力する一行の操作をコマンドと呼びます。OSはWindowsなど、ファイルやアプリを管理する基本のソフトウェアです。まずPython公式のダウンロード案内で使用中のOS向けの手順を開き、Pythonをインストールします。その後、ターミナルを開きます。WindowsではPowerShell、macOSやLinuxではターミナルを使えます。下の一行を入力してEnterを押します。Windowsでpythonが見つからずpyが使える場合は、以降のpythonをpyへ読み替えます。

python --version

これはPythonのコードではなく、OSへ実行を頼むコマンドです。バージョンが表示されれば準備ができています。後の実験では使用したバージョンも記録します。インストールは Python公式 の案内を使ってください。

ファイルを実行する

Windowsでは次の順番で進めます。文章を書くアプリをテキストエディターと呼びます。メモ帳でもこの練習ができます。

  1. ファイルを探すアプリ（エクスプローラー）で、書き込み可能な場所に study フォルダを作ります。
  2. メモ帳へ、下の三行だけを入力します。
  3. 「名前を付けて保存」でstudyフォルダを選びます。ファイルの種類を「すべてのファイル」にし、名前を first.py にします。
  4. エクスプローラーでファイル名の末尾を確認します。末尾の種類を示す部分が拡張子で、Pythonのファイルは .py です。.py.txt になったら保存し直します。
  5. エクスプローラーのアドレス欄からstudyフォルダの場所をコピーします。この場所を示す文字列がパスです。
  6. PowerShellを開き、cd "ここをコピーした場所に置き換える" と入力します。cd は作業場所を変える命令です。引用符は残し、中身を実際の場所に置き換えます。
  7. dir と入力して一覧に first.py があることを確認し、python first.py を実行します。先の確認で py を使った場合は py first.py です。

macOSやLinuxでも、保存後にターミナルで cd "保存先の場所"、ls で一覧を確認します。Pythonの起動名が python3 なら、バージョン確認と実行の両方を python3 に読み替えます。

correct = 80
total = 100
print(correct / total)

出力は0.8です。print(...)は括弧内の結果を画面へ出す関数です。=は、右側の値へ左側の名前を付ける代入です。数学の「左右が等しいという条件」とは異なります。等しいかを調べるPythonの記号は==です。

correct = 90に変えて再実行すると0.9になります。変数とは、値を参照するために付ける名前です。同じ名前へ別の値を割り当てることもできます。

値には種類がある

3は整数のint、0.5は小数を扱うfloat、"cat"は文字列のstr、TrueとFalseは真偽値のboolです。文字列を囲む引用符は、そこがプログラムの命令ではなく文字のデータだと示します。

type(x)は、xが整数・文字列などのどの型かを調べる操作です。下の出力はPythonの型の名前を表示します。

x = 3
print(type(x))
print(3 + 4)
print("3" + "4")
print(3 == 4)

結果は順に整数の型情報、7、文字列34、Falseです。数の3と文字の"3"は違います。int("3")で整数へ変換できますが、int("cat")は変換できずエラーになります。

Pythonの掛け算は*、割り算は/、べき乗は**です。//は床除算、%は剰余を表します。正の整数で7を3で割れば、7//3が2、7%3が1です。

エラーは観測結果

pritn(3)と打つとNameErrorになります。知らない名前が使われたという意味です。英語のエラー表示を全部理解する必要はありません。まず最後の行にあるエラーの種類と、直前のファイル名・行番号を確認します。予想した結果と実際の結果を分けて記録し、一箇所ずつ直します。

エラーが出たら、この順に確認する

表示・状態 意味と次の操作
pythonが見つからない Windowsなら py --version を確認。両方なければ公式のインストール手順を確認し、ターミナルを開き直す
can't open file / No such file 指定したファイルが見つからない。dir（macOS/Linuxではls）で名前と場所を確認する
画面に >>> がある Pythonの入力画面に入っている。exit()で戻ってから python first.py を入力する
SyntaxError Pythonの書き方として読めない箇所がある。示された行と、その前の行の括弧・引用符を確認する
NameError 知らない名前が使われた。printのつづりや変数名の大小文字を確認する

エラー文は消す前にメモへ残しましょう。解決しなければ、保存の確認へ戻り、どの番号の手順で止まったかを記録します。今日は画面のコードを紙で追うところまででもかまいません。

演習

1・実行前に予想する

print(2 + 3 * 4)とprint((2 + 3) * 4)の出力を予想し、動かしてください。

解答と考え方を読む

14と20です。算数で学んだ優先順位と一致します。実行できたことだけでなく、予想と一致したかも記録します。

2・代入の意味

x=3、次にx=x+2、最後にprint(x)を実行するとどうなりますか。

解答と考え方を読む

5です。二行目は古いxの値3へ2を足し、その結果5へxという名前を付け直します。数学の方程式x=x+2を解いているのではありません。

3・型の区別

"12" + "3"とint("12") + 3の結果はどう違いますか。

解答と考え方を読む

前者は文字列"123"、後者は整数15です。ファイルから読み込んだ数値は文字列であることがあるので、型の確認が必要です。

4・研究の計算を実装する

正解58件、全体100件の正解率を計算して表示する三行のプログラムを書いてください。

解答と考え方を読む

correct = 58、total = 100、print(correct / total)です。結果は0.58。百分率で表示するならさらに100を掛けます。

5・エラーを直す

print(score)だけのファイルでNameErrorが出ました。原因と、最小の修正を書いてください。

解答と考え方を読む

scoreという名前にまだ値を割り当てていません。前にscore = 0.8を追加すれば表示できます。実際のプログラムでは値をどこで作るべきかを考えます。

到達課題と出典

算数の章の全体正解率を計算するプログラムを作り、数字を変えて再実行してください。言語仕様は Python公式チュートリアル に対応します。同チュートリアル自体はプログラミング経験者向けなので、本章では実行と型から説明しました。
