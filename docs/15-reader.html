15 行列は、まとめて変換する道具：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

この章は、一回一ページで進める

全5ページです。後のページ名は行き先の案内で、今ここで暗記する用語ではありません。各回の読解・手計算・演習を分け、実装は別の回にできます。時間は初学者向けの編集上の目安で、受講者の実測値ではありません。

  • 1．行列と列ベクトルで二つの出力を作る
  • 2．行と列の内積で行列積を作る
  • 3．行と列を交換する
  • 4．方向の重複とランクを調べる
  • 5．連立方程式を解き、コードで確認する

数の向きと、行・列を決める

紙に数2と3を縦に並べると、2行1列の表になります。この縦一列に置いたベクトルが**列ベクトル**です。横一行なら行ベクトル。(2,3)は数の並びの略記で、掛け算をするときは縦・横の約束を明記します。列ベクトルへ戻れます。

縦に置いたx 値
上の成分 2
下の成分 3

入力x=(2,3)から、出力の一つ目を2x₁+x₂、二つ目を−x₁+3x₂にしたいとします。それぞれ内積です。第5章で学んだ係数を二行に並べたA=[[2,1],[-1,3]]を使うと、二つの計算をy=Axとまとめられます。結果は(7,7)です。

行列は数を行と列に並べたものです。Aは2行2列。形を(2,2)と書きます。一般にAがm行n列、xがn個の列ベクトルなら、Axはm個の列ベクトルです。内側のnが一致している必要があります。

1・行列とベクトル

[[2,0],[1,3]]に列ベクトル(4,2)を掛けてください。

解答と考え方を読む

第一成分2×4+0×2=8、第二成分1×4+3×2=10なので(8,10)です。

四つの出力を一つずつ求める

A=[[1,2],[3,4]]、B=[[5,6],[7,8]]とします。ABの左上は、Aの最初の行とBの最初の列の内積なので1×5+2×7=19。同様に右上22、左下43、右下50です。各要素を単に掛ける計算とは違います。

(AB)ᵢⱼ=Σₖ Aᵢₖ Bₖⱼと書けます。iは出力の行、jは出力の列、kは足し合わせる方向です。Aが(m,n)、Bが(n,p)ならABは(m,p)。一般にはABとBAは同じにならず、片方しか計算できない場合もあります。

2・形

(3,4)の行列と(4,7)の行列の積の形は何ですか。逆順も可能ですか。

解答と考え方を読む

(3,7)です。逆順は内側が7と3で一致しないため計算できません。

3・交換できない例

A=[[1,1],[0,1]]、B=[[2,0],[0,3]]のABとBAを求めてください。

解答と考え方を読む

AB=[[2,3],[0,3]]、BA=[[2,2],[0,3]]です。右上が違い、変換の順序に意味があると分かります。

一行を一列へ移す

転置Aᵀは行と列を交換します。形(m,n)は(n,m)へ変わります。転置は数の並び順を交換する操作で、各値そのものを変える操作ではありません。

元のAの行 値
1行目 1, 2, 3
2行目 4, 5, 6

転置後は三行になり、一行目(1,4)、二行目(2,5)、三行目(3,6)です。元の一行を、転置後の一列へ移しました。文章中の情報同士を比べる応用は第31章で学びます。今は転置の操作だけを確認します。

4・転置を表へ戻す

A=[[1,2],[3,4],[5,6]]の形とAᵀの形・全要素を書いてください。

解答と考え方を読む

Aは(3,2)、Aᵀは(2,3)で[[1,3,5],[2,4,6]]です。

二つの方向で全部を作れるか

二次元のベクトルは、横へ一つ進む(1,0)と縦へ一つ進む(0,1)を掛けたり足したりして表せます。(2,3)=2(1,0)+3(0,1)です。このように数を掛けて足す組合せを線形結合と呼びます。

どのベクトルも作れ、かつ一つの方向をほかの方向の組合せでは作れない基本方向の組が基底です。その本数が次元です。(1,2)と(2,4)なら後者は前者の2倍で、一方向分しかありません。このようにほかの列で作れない独立な列の最大数が**ランク**です。基底・ランクへ戻れます。

5・独立な方向

(1,2)と(2,4)は二次元全体の基底になりますか。

解答と考え方を読む

なりません。後者は前者の2倍で同じ直線上にあり、二つを組み合わせてもその直線以外へ進めません。

同じ条件を表と式で書く

x+y=5、x−y=1を足すと2x=6なのでx=3、y=2です。これもAx=bという行列の形にできます。逆行列は変換を元に戻す行列ですが、すべての行列に存在するわけではありません。二行が同じなら、二つの独立な条件がありません。数値計算では逆行列を明示的に作るより、連立方程式を解く専用関数を使います。

NumPyは数の配列を扱うライブラリです。準備がまだなら第12章へ戻ってください。import numpy as npはNumPyをnpという短い名前で使う指定、np.arrayは数の並びから計算用の配列を作る操作です。

import numpy as np
A = np.array([[1., 1.], [1., -1.]])
b = np.array([5., 1.])
x = np.linalg.solve(A, b)
print(x)
print(A @ x)

NumPyは数の配列を扱うライブラリです。未導入なら第12章の仮想環境とインストール手順へ戻ります。@は行列積で、*は要素ごとの積です。出力は[3,2]と[5,1]になります。

6・方程式

2x+y=7、x−y=2を解いてください。

解答と考え方を読む

二式を足して3x=9、x=3。x−y=2からy=1。元の両式へ代入して確認できます。
