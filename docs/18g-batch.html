18-7 例ごとの寄与からXᵀGを作る

読む・手計算の目安：25〜40分。演習は10〜20分、コード実行は別の回へ分けられます。時間は編集上の目安です。

四つの重みを一つずつ微分する

まず一つの例、二つの入力と二つの出力だけで確かめます。

X=[[2,3]]、W=[[1,4],[2,5]]、b=[0,0]ならY=XW+b=[[8,23]]です。損失をL=y₁+2y₂とする微分の模型では、上流の勾配G=[[1,2]]。この模型は微分を確認するためのもので、無限に小さくできる線形のLを訓練課題として推奨する例ではありません。

重み どの出力に使うか 入力×上流 その重みの勾配
W₁₁ y₁ 2×1 2
W₁₂ y₂ 2×2 4
W₂₁ y₁ 3×1 3
W₂₂ y₂ 3×2 6

四つを同じ形へ並べると[[2,4],[3,6]]。Xᵀ=[[2],[3]]とG=[[1,2]]を掛けた結果XᵀGです。公式を暗記する前に、この四つの掛け算を確認します。

二つの例の寄与を足す

二例目をXの第二行[1,−1]、その上流の第二行を[3,4]とします。二例目の重みへの寄与は[[3,4],[−3,−4]]。同じWを二例とも使うので、二つの寄与を足して[[5,8],[0,2]]になります。

一般にXが(batch,in)、Wが(in,out)、Gが(batch,out)なら、Wの勾配はXᵀGで(in,out)。記号inは入力の個数、outは出力の個数です。ここでbatchは、いくつの例をまとめたか。

一要素ならYᵢⱼ=ΣₖXᵢₖWₖⱼ、Wₖⱼへの微分はΣᵢXᵢₖGᵢⱼです。iは例、jは出力、kは入力。先ほどの表の「入力×上流を、例について足す」をまとめた式です。

入力とbiasへの勾配も戻す

入力への勾配はGWᵀです。一例目は[1×1+2×4, 1×2+2×5]=[9,12]。二例目は[19,26]。biasは同じ出力列へ1倍で作用するので、例の軸を足して[1+3,2+4]=[4,6]になります。

import numpy as np
X = np.array([[2., 3.], [1., -1.]])
W = np.array([[1., 4.], [2., 5.]])
G = np.array([[1., 2.], [3., 4.]])
dW = X.T @ G
dX = G @ W.T
db = G.sum(axis=0)
print(dW, dX, db)
assert np.allclose(dW, [[5., 8.], [0., 2.]])
assert np.allclose(dX, [[9., 12.], [19., 26.]])
assert np.allclose(db, [4., 6.])

損失を例の平均にする場合は、平均にした損失からGを求めます。二例の和のGを2で割ったものが平均のGなら、全ての勾配も半分です。既に平均が含まれたGへもう一度1/batchを掛けません。入力が読めなければ行列積、一成分の微分なら一出力の表へ戻れます。

10・和と平均を分ける

このページの二例の和の損失を、二例の平均へ変えました。Wとbiasの勾配は何ですか。

解答と考え方を読む

和のGを2で割るため、Wの勾配は[[2.5,4],[0,1]]、biasの勾配は[2,3]。平均が入ったGをもう一度割らないようにします。

章の到達課題と出典

L(w)=(2w+1)²について、手計算と中央差分(L(w+h)−L(w−h))/(2h)をw=1で比べてください。正解は12です。MIT Multivariable Calculus が関連します。
