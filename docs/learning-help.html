止まったところから、また始める

同じ箇所を読み返して進めないときは、全56章の補習から該当章を選びます。具体例→手助け付き問題→自力の問題の順で、どの一行が止まったかを確かめます。前提へ戻るリンクは各補習にあります。

一章を一度に終える必要はありません。表示時間は編集上の目安で、読む速さや操作環境によって変わります。演習や実装は別の日に分けられます。

小ページから卒業研究までの進め方で、平日30分の区切り、共有PCでの実行、参照ページの使い方を確認できます。

今日の5〜10分を決める

  1. 見出しを一つ選びます。
  2. 具体例を一つ、紙かコードで確かめます。
  3. 「できたこと」「止まった一文」「次にすること」を一行ずつ残します。
  4. 次回はその記録と具体例から再開します。

分からない語は説明順序の問題かもしれません。三回読んでも分からないときは、下の補習へ移ってかまいません。保留した内容は、できた扱いにせず記録します。

スマートフォンとパソコンを使い分ける

スマートフォンでは講義、図、手計算、解答の確認まで進められます。ファイルを扱うコードの実習は、パソコンを使える回へ分けましょう。このサイトのコード欄は実行環境ではありません。

次へ進む前の確認

到達目標について、数字を変えた例を一つ説明できるか試します。できなければ具体例と補習へ戻ります。発展課題を保留することはできますが、後の章の前提として使うときには戻って確かめましょう。

行列から微分へ進む途中で止まったら

  • 行と列の掛け算：行列積の四要素。
  • 行列の各微分：ヤコビ行列の四つのセル。
  • 戻る向きが分からない：JVPとVJPの二つの問い。
  • XᵀGが読めない：一出力の三つの勾配から例ごとの寄与へ。

同じ式を何度も眺めるより、表の一セルを先に説明します。ここで保留した内容は、次に前提として使う前に戻って確認してください。
