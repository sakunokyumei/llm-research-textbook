18 偏微分・連鎖律・勾配：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

この章は、一回一ページで進める

全7ページです。後のページ名は行き先の案内で、今ここで暗記する用語ではありません。各回の読解・手計算・演習を分け、実装は別の回にできます。時間は初学者向けの編集上の目安で、受講者の実測値ではありません。

  • 1．一つの入力だけを変え、偏微分を求める
  • 2．一つの経路で連鎖律を確かめる
  • 3．勾配の逆へ、小さく動く
  • 4．微分を一セルずつ表へ並べる
  • 5．入力の方向と、出力から戻る勾配を分ける
  • 6．一出力の重みとbiasを微分する
  • 7．例ごとの寄与からXᵀGを作る

つまみが二つあるとき

予測を調整するつまみがxとyの二つあるとします。結果がf(x,y)=x²+3yなら、xだけを少し変えるとどうなるでしょう。yを固定してxで微分すると2xです。この「ほかの変数を固定する微分」を偏微分と呼び、∂f/∂xと書きます。同様に∂f/∂y=3です。

偏微分を並べたベクトルが勾配で、∇f=(2x,3)。x=1なら(2,3)です。小さな移動Δ=(Δx,Δy)による関数値の変化は、微分可能な点の近くでf(x+Δx,y+Δy)−f(x,y)≈∇f·Δと近似できます。

たとえば(1,2)からxだけ0.01増やすと、変化は約2×0.01=0.02。正確には1.01²−1²=0.0201です。移動が大きくなると一次近似の誤差も無視できなくなります。

Δ（デルタ）はここでは移動した差を表します。一次近似は、曲がった変化を近くの直線・平面の変化で置き換えることです。偏微分・勾配へ戻れます。

変えるもの 入力 関数値 元の7からの差
何も変えない (1,2) 7 0
xだけ0.01増やす (1.01,2) 7.0201 0.0201
yだけ0.01増やす (1,2.01) 7.03 0.03

1・偏微分

f(x,y)=xy+y²の∂f/∂x、∂f/∂yと、(x,y)=(2,3)での勾配を求めてください。

解答と考え方を読む

∂f/∂x=y、∂f/∂y=x+2y。勾配は(3,8)です。xで微分するときyを定数として扱います。

値は前へ、変化率は後ろへ

u=2x+1、L=u²を考えます。xからuへの変化率は2、uからLへの変化率は2uです。両者を掛けるとdL/dx=(dL/du)(du/dx)=2u×2。x=1ならu=3なので12です。これが連鎖律です。

ニューラルネットワークは多数の関数をつないだものです。各部品の局所的な微分を掛け、分岐している経路の寄与は足します。大きな式を丸ごと展開せず、計算のつながりをグラフとして保存し、出力から入力へ逆にたどると効率的です。これを逆伝播と呼びます。

2・連鎖律

L=(3x−1)²のx=2での微分を求めてください。

解答と考え方を読む

u=3x−1=5、dL/du=2u=10、du/dx=3。したがって30です。

3・分岐の寄与

L=x×xの微分で、片方のxだけの影響をたどると何を見落としますか。

解答と考え方を読む

xから積への経路が二つあります。それぞれxの寄与があるので足して2xです。一方しか数えないとxになってしまいます。

歩幅で結果が変わる

同じ小さなユークリッド距離だけ動くなら、勾配方向は一次近似で最も値が増える方向です。値を減らしたければ逆へ動きます。更新式はθ_new = θ − η∇L(θ)。θは調整する値のベクトル、Lは小さくしたい損失、ηは歩幅に相当する学習率です。

L(w)=(w−3)²をw=0から始めます。微分は2(w−3)=−6。η=0.1ならw_new=0−0.1×(−6)=0.6。損失は9から5.76へ下がります。しかしη=2ならw_new=12となり、損失は81へ増えます。勾配が正しくても、歩幅が大きすぎれば失敗します。

単位方向は、長さが1の方向ベクトルです。方向(3,4)の長さは5なので、各成分を5で割った(3/5,4/5)は長さ1になります。長さ0のベクトルではこの割り算はできません。単位方向へ戻れます。

4・勾配降下

L(w)=(w−2)²、w=0、学習率0.25のとき一回更新してください。

解答と考え方を読む

勾配は−4なのでw_new=1。損失は4から1へ下がります。

5・方向微分

勾配が(3,4)、単位方向が(1,0)のとき、その方向の変化率はいくつですか。

解答と考え方を読む

内積3×1+4×0=3です。勾配方向の単位ベクトルは(3/5,4/5)で、その方向なら変化率は5になります。

出力を二つにする

出力が二つになると、一つの微分係数だけでは足りません。f(x,y)=(x²,xy)を考え、出力をf₁=x²、f₂=xyと分けます。まず入力の片方を固定し、一つの成分ずつ微分します。

出力 xを変えた変化率 yを変えた変化率
f₁=x² 2x 0
f₂=xy y x

f₁はyを使わないので、その変化率は0。f₂をxで微分すると、固定したyが係数になりyが残ります。この表が**ヤコビ行列**Jです。行は出力、列は入力。入力n個・出力m個なら(m,n)です。ヤコビ行列へ戻れます。

(x,y)=(2,3)ならJ=[[4,0],[3,2]]。各セルを、偏微分のページの操作へ戻して説明してください。ここではまだJ全体をほかのベクトルへ掛けません。

6・四つのセルを作る

f(x,y)=(x+y,3y)のヤコビ行列を、四つの偏微分から作ってください。

解答と考え方を読む

[[1,1],[0,3]]です。二つ目の出力はxを使わないので左下は0。

このページの数値例を、数字を変えて一つ説明できたら区切れます。解答を隠して確認してください。止まったら中断・補習の手引きへ戻れます。

同じJ=[[4,0],[3,2]]に対して、二つの違う問いを考えます。

入力を動かしたら出力はどう動くか

入力を方向v=(1,−1)へ小さく動かします。出力の一次近似はJv=(4,1)。一行目は4×1+0×(−1)=4、二行目は3×1+2×(−1)=1です。これを**JVP**と呼びます。正確な変化は、移動量hで割ったとき(4+h,1−h)なので、hが小さいと(4,1)へ近づきます。

損失の変化率を入力へ戻す

損失をL=2f₁+f₂と定めます。出力をどちらか一つだけ1動かしたときのLの変化率はg=(2,1)。この出力側の変化率を「感度」とも呼びます。xへの影響はf₁経由の4×2とf₂経由の3×1を足して11。yへの影響は0×2+2×1=2です。

戻す入力 f₁経由 f₂経由 合計
x 4×2=8 3×1=3 11
y 0×2=0 2×1=2 2

列ベクトルとして書けばJᵀg=(11,2)。行ベクトルとして書く場合はgᵀJ=(11,2)で、表す向きが違うだけです。これがVJPの計算です。JVPの入力方向vと、VJPの出力感度gを同じものとして扱わないでください。JVP/VJPへ戻れます。

手計算をコードで照合する

import numpy as np
J = np.array([[4., 0.], [3., 2.]])
v = np.array([1., -1.])
g = np.array([2., 1.])
print(J @ v)
print(J.T @ g)
print(g @ J)
assert np.allclose(J @ v, [4., 1.])
assert np.allclose(J.T @ g, [11., 2.])
assert np.allclose(g @ J, [11., 2.])

NumPyの一次元配列は、行か列かをshapeで区別していません。ここでは式の意味を先に定め、@の結果を確認します。二次元で列を明示するならgを(2,1)に整え、Jᵀgも(2,1)になります。自動微分のコードは第26章で確認します。仕様の出典：PyTorchのJVPとVJP。

7・形を確認する

入力4個、出力3個の関数でJacobianと出力の勾配の形を決め、Jᵀgの形を確認してください。

解答と考え方を読む

Jは(3,4)、gは(3,)。(4,3)と(3,)の積なので入力勾配は(4,)です。

8・JVPを計算する

上のJで入力方向v=(0,1)、出力感度g=(1,0)のJvとJᵀgを求めてください。

解答と考え方を読む

Jv=(0,2)、Jᵀg=(4,0)。同じ微分行列を使いますが、掛ける方向と意味が異なります。

同じ連鎖律を三つの入力へ使う

入力がx=2、重みがw=3、ずれがb=1の一出力を考えます。y=xw+b=7、損失をL=y²とするとL=49です。線形層という名前は、ここでは行列積と加算を行う部品を指します。行列を掛け、一定のずれを足すこの変換を、数学ではアフィン変換と呼びます。b=0の場合の行列積だけの変換は線形変換です。

後の計算から届く出力の変化率はG=dL/dy=2y=14。これは**上流の勾配**です。Lではなく、yに対するLの微分の値を受け取ります。

変えるもの yの変化率 上流G Lまでの変化率
w x=2 14 2×14=28
b 1 14 1×14=14
x w=3 14 3×14=42

この表は、前の一経路の連鎖律を三回使っただけです。biasは掛けた後に加えるずれ、線形層はこの計算を複数の入力・出力へまとめる部品です。線形層とbias・上流の勾配へ戻れます。

9・一出力の勾配を計算する

x=3,w=2,b=0,L=y²ならy、G、wとbへの勾配はいくつですか。

解答と考え方を読む

y=6、G=12、wの勾配3×12=36、bの勾配12です。

四つの重みを一つずつ微分する

まず一つの例、二つの入力と二つの出力だけで確かめます。

X=[[2,3]]、W=[[1,4],[2,5]]、b=[0,0]ならY=XW+b=[[8,23]]です。損失をL=y₁+2y₂とする微分の模型では、上流の勾配G=[[1,2]]。この模型は微分を確認するためのもので、無限に小さくできる線形のLを訓練課題として推奨する例ではありません。

重み どの出力に使うか 入力×上流 その重みの勾配
W₁₁ y₁ 2×1 2
W₁₂ y₂ 2×2 4
W₂₁ y₁ 3×1 3
W₂₂ y₂ 3×2 6

四つを同じ形へ並べると[[2,4],[3,6]]。Xᵀ=[[2],[3]]とG=[[1,2]]を掛けた結果XᵀGです。公式を暗記する前に、この四つの掛け算を確認します。

二つの例の寄与を足す

二例目をXの第二行[1,−1]、その上流の第二行を[3,4]とします。二例目の重みへの寄与は[[3,4],[−3,−4]]。同じWを二例とも使うので、二つの寄与を足して[[5,8],[0,2]]になります。

一般にXが(batch,in)、Wが(in,out)、Gが(batch,out)なら、Wの勾配はXᵀGで(in,out)。記号inは入力の個数、outは出力の個数です。ここでbatchは、いくつの例をまとめたか。

一要素ならYᵢⱼ=ΣₖXᵢₖWₖⱼ、Wₖⱼへの微分はΣᵢXᵢₖGᵢⱼです。iは例、jは出力、kは入力。先ほどの表の「入力×上流を、例について足す」をまとめた式です。

入力とbiasへの勾配も戻す

入力への勾配はGWᵀです。一例目は[1×1+2×4, 1×2+2×5]=[9,12]。二例目は[19,26]。biasは同じ出力列へ1倍で作用するので、例の軸を足して[1+3,2+4]=[4,6]になります。

import numpy as np
X = np.array([[2., 3.], [1., -1.]])
W = np.array([[1., 4.], [2., 5.]])
G = np.array([[1., 2.], [3., 4.]])
dW = X.T @ G
dX = G @ W.T
db = G.sum(axis=0)
print(dW, dX, db)
assert np.allclose(dW, [[5., 8.], [0., 2.]])
assert np.allclose(dX, [[9., 12.], [19., 26.]])
assert np.allclose(db, [4., 6.])

損失を例の平均にする場合は、平均にした損失からGを求めます。二例の和のGを2で割ったものが平均のGなら、全ての勾配も半分です。既に平均が含まれたGへもう一度1/batchを掛けません。入力が読めなければ行列積、一成分の微分なら一出力の表へ戻れます。

10・和と平均を分ける

このページの二例の和の損失を、二例の平均へ変えました。Wとbiasの勾配は何ですか。

解答と考え方を読む

和のGを2で割るため、Wの勾配は[[2.5,4],[0,1]]、biasの勾配は[2,3]。平均が入ったGをもう一度割らないようにします。
