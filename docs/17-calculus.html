17 微分は、今ここでの変わり方

到達目標：差分から微分へ進み、傾きを計算する

前提：06・07 演習 6 問

この瞬間の速度はどう測るか

車が2時間で100km進めば平均速度は50km/hです。しかし途中で止まったかもしれません。今この瞬間の速度を知るには、見る時間幅を短くしていきます。この発想が微分です。

位置をf(t)=t²とする模型で、t=2からt=3の平均変化率は(9−4)/(3−2)=5。t=2から2.1では(4.41−4)/0.1=4.1。幅hを使って書くと、((2+h)²−2²)/h=4+hです。hを0に近づけると4へ近づきます。この値をt=2の微分係数と呼びます。

h=0を直接代入すると0/0になってしまいます。「0を代入する」のではなく「0へ近づくとどの値へ近づくか」を考えるのが極限です。記号limで表します。関数全体について微分係数を返す新しい関数を導関数と呼び、f'(t)と書きます。

式を一般化する

同じ計算をxで行うと、((x+h)²−x²)/h=2x+h。したがってf(x)=x²の導関数はf'(x)=2xです。二乗の微分が2xになる理由は、単なる暗記ではなくこの差分から説明できます。

基本的な規則として、定数の微分は0、xのn乗はn xⁿ⁻¹、和は微分の和です。exp(x)の微分はexp(x)、ln(x)の微分は1/x（x>0）。積は(fg)'=f'g+fg'となり、f'g'ではありません。公式には定義域や微分可能性の条件があります。

関数 導関数 例
3 0 入力を変えても一定
3x+2 3 傾きが常に3
x² 2x x=−1なら傾き−2
x³ 3x² x=2なら傾き12

微分できない点もある

絶対値|x|は0で尖っています。左からの傾きは−1、右からは1なので、一つの傾きに決まりません。すべての関数がすべての点で微分できるわけではありません。機械学習のライブラリがそこで特定の値を返すことは、数学的な微分が存在することとは別です。

def f(x):
    return x * x

x = 2.0
for h in [0.1, 0.01, 0.001]:
    print(h, (f(x + h) - f(x)) / h)

結果は約4.1、4.01、4.001です。hを無限に小さくすれば実装も無限に正確になるわけではありません。有限精度の引き算では、近い数の差が不正確になる場合があります。

演習

1・平均変化率

f(x)=x²のx=1からx=3までの平均変化率を求めてください。

解答と考え方を読む

(9−1)/(3−1)=4です。x=1の瞬間の傾き2とは異なります。

2・差分から導く

f(x)=3x+2について、(f(x+h)−f(x))/hを整理してください。

解答と考え方を読む

(3x+3h+2−3x−2)/h=3。hが0でない限り一定なので、微分係数も3です。

3・導関数

f(x)=2x³−4x+7の導関数と、x=2での値を求めてください。

解答と考え方を読む

f'(x)=6x²−4、x=2では24−4=20です。

4・傾きの符号

f(x)=x²のx=−2では、xを少し増やすと値は増えますか。

解答と考え方を読む

傾き2x=−4なので局所的には減ります。実際にf(−2)=4、f(−1.9)=3.61です。

5・積の微分

x×xの微分を積の公式で求めてください。

解答と考え方を読む

1×x+x×1=2xです。各微分の積1×1=1ではありません。

6・極限と実装

差分でh=0をそのまま使ってよいですか。また小さくし続ければ必ず精度が上がりますか。

解答と考え方を読む

h=0では分母が0になるため使えません。小さすぎるhでは浮動小数点の丸めや桁落ちにより精度が悪化し得ます。式としての極限と数値近似を分けます。
