44 量子化・蒸留・枝刈り：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

細かい目盛りを減らす

実数を限られた整数の目盛りへ近似するのが量子化です。単純な対称量子化ではq=clip(round(x/s),q_min,q_max)、復元はx̂=sq。sは目盛りの幅です。x=0.26、s=0.1ならq=3、復元0.3、誤差0.04になります。

目盛りを粗くすると保存量は減りますが誤差が増えます。少数の極端に大きな値に合わせて範囲を広げると、小さい値を区別しにくくなります。per-channelやgroup単位でscaleを分ける方法は、その交換を調整します。scale等の管理情報も容量に含めます。

何を量子化するか

重みだけ、活性化も、KV cacheも、という対象の違いがあります。PTQは学習後に量子化し、QATは量子化の影響を意識して学習します。GPTQは層の出力の再構成を意識して近似的な二次情報を使い、AWQは活性化から重みの重要性を扱う方法です。単に「4bit」という一語では方式が分かりません。

4bit化したからFP16の4倍速いとは限りません。復元、メモリ移動、対応kernel、batch形状、装置に依存します。速度、メモリ、精度、入力長ごとの品質を測ります。校正データもtrain/validationの方針に従い、testで選びません。

教師から生徒へ

蒸留は大きな教師モデルの出力分布や生成例などを生徒へ学ばせる方法です。正解ラベルだけでなく、他の候補への確率にも情報があるかもしれません。一方、教師の誤りや偏りも受け継ぎ得ます。教師の能力を必ず全て保存できるわけではありません。

枝刈りは重み、ヘッド、層などの一部を取り除く方法です。バラバラの重みを0にする非構造的な疎性と、まとまった成分を除く構造的な疎性では、実装で速くなる条件が違います。dense kernelで0を掛け続けるなら、ゼロが増えても演算が省かれない場合があります。

二つの目盛りで出力まで確かめる

per-channelは出力の成分ごと、groupはまとめた一群ごとに目盛りの幅を分ける指定です。zero pointは整数0以外の値へ実数の0を対応させる場合の基準。今回は対称量子化で0をそのまま0へ対応させます。

import numpy as np
W = np.array([[0.26, -0.34], [0.12, 0.49]])
x = np.array([2., 1.])
s = 0.1
q = np.clip(np.round(W / s), -7, 7)
restored = s * q
print(W @ x, restored @ x)
print(np.linalg.norm(W - restored))

roundは近い整数へ丸め、clipは範囲−7〜7へ制限します。NumPyのroundはちょうど中間の場合に偶数側へ丸める規約で、この入力には中間値がありません。元の出力は(0.18,0.73)、復元後は(0.3,0.7)。重み誤差が出力へどう響くかは入力にも依存します。ノルムは第16章へ、行列積は第15章へ戻れます。

演習

1・量子化

x=−0.34、s=0.1、範囲内として量子化・復元・絶対誤差を求めてください。

解答と考え方を読む

q=−3、復元−0.3、絶対誤差0.04です。

2・理想容量

100万個の重みをFP16から4bitへ変えると、重み本体の理想的な容量は何byteから何byteですか。

解答と考え方を読む

200万byteから50万byteです。ただしscale、zero point、packing、その他のモデル状態は別です。

3・校正

評価セットを使って最もよい量子化scaleを選ぶと何が問題ですか。

解答と考え方を読む

評価データへ合わせ込んでしまいます。校正用データと最終評価を分離します。

4・疎性

重みの90%が0になったので、必ず10倍速いと言えますか。

解答と考え方を読む

言えません。ゼロを省く対応kernelや形式が必要で、転送・索引・不均一な処理の費用もあります。

5・蒸留の評価

教師への一致率だけで、生徒の回答品質を十分に測れますか。

解答と考え方を読む

不十分です。教師の誤答まで一致することがあるため、独立した正解や用途の基準でも評価します。

到達課題と出典

小行列を対称量子化し、重みの誤差と同じ入力への出力誤差を比較します。保存量の概算を実速度の測定と分けます。GPTQ、AWQ、Distilling the Knowledge in a Neural Network を参照。
