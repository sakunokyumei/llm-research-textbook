09 条件・繰り返し・関数：まとめて参照

長い参照ページです。初めて学ぶときは小ページの順序を使い、ここへ戻って式やコードを引けます。

人が毎回判断しなくてよいように

点数が合格基準以上か、100件の答えが正しいか。コンピュータに任せたい作業には、判断と繰り返しが含まれます。ifは条件で処理を分け、forは複数の値に対して処理を繰り返します。

score = 75
if score >= 60:
    print("合格")
else:
    print("もう一度練習")

for value in [2, 4, 6]:
    print(value * 2)

出力は「合格」、4、8、12です。>=は以上、[]で囲んだ値の並びはリストです。コロンの次に続く行は空白4個分だけ下げます。この字下げ、つまりインデントが同じ処理のまとまりを示します。見た目だけの飾りではありません。

足し合わせる処理を追う

total = 0
for value in [2, 4, 6]:
    total = total + value
print(total)

最初にtotalは0。1回目に2、2回目に6、3回目に12になります。最後のprintは字下げされていないので、ループが終わった後に一度だけ実行されます。

range(3)は0,1,2という三つの整数を順に使うための仕組みです。3を含みません。whileは条件が真の間繰り返します。終了条件を変え忘れると終わらなくなるので、回数が決まる場合はforから始めましょう。

処理へ名前を付ける

関数は、入力を受け取り、処理して結果を返す仕組みです。defで定義し、returnで返します。括弧内の名前を引数と呼びます。

def accuracy(correct, total):
    if total <= 0:
        raise ValueError("totalは正の数にしてください")
    return correct / total

result = accuracy(8, 10)
print(result)

結果は0.8です。raiseは不適切な入力をエラーとして知らせます。printは表示、returnは呼び出し元へ値を返す操作です。表示しただけでは、別の計算へ結果を渡せません。

機械学習の実験も、小さな関数を組み合わせます。データを読む、予測する、誤差を測る、保存する。役割を分けると、どこで間違ったかを調べやすくなります。

演習

1・境界を試す

上の合格判定でscore=60と59の場合を予想してください。

解答と考え方を読む

60は合格、59はもう一度練習です。境界そのものと、そのすぐ隣を試すと>と>=の取り違えを見つけやすくなります。

2・ループを手で追う

total=1から始め、[2,3,4]を順に掛けると最後はいくつになりますか。

解答と考え方を読む

1×2=2、2×3=6、6×4=24。積の初期値は1です。0から始めるとずっと0になります。

3・rangeの終端

for i in range(4): print(i)は何を表示しますか。

解答と考え方を読む

0,1,2,3の四つです。4は含みません。数学で1〜4を足すならrange(1,5)を使います。

4・関数を作る

入力xの二乗に1を足して返す関数square_plus_oneを書いてください。

解答と考え方を読む

def square_plus_one(x):の次の行を字下げしてreturn x ** 2 + 1と書きます。x=3で10、x=−2で5かを確認します。

5・終了条件

x=0の後、while x<3:の中でprint(x)だけを実行しました。なぜ終わらないのでしょう。

解答と考え方を読む

xが変わらず、条件x<3がずっと真だからです。ループ内にx = x + 1を加えるか、for x in range(3)を使います。
