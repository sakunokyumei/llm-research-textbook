算数から数式へ

03 数・分数・割合を量として考える

今回取り組むこと：分数を同じ大きさに分けた量として説明する

前提：02 作業する場所と、保存する場所 演習 2 問・確認 0 件

第3章は5ページ。今日はこのページを5〜10分で読み、確認問題を一つ解ければ区切れます

時間は編集上の目安です。見出し一つで休憩しても大丈夫。中断・再開と補習の手引きも使ってください。

本編で止まったら、この章の例題・手助け付き問題・自力の問題を使えます。練習の進め方

800個のお菓子を分ける

800個のお菓子のうち、4分の1を明日のために残すとします。4分の1とは、全体を同じ大きさの4組に分けたうちの1組です。800÷4=200なので、残すのは200個です。この「同じ大きさに分ける」という考えが分数の出発点です。

3/4は4等分した3個分を表します。下の4を分母、上の3を分子といいます。3/4 = 3÷4 = 0.75です。小数の0.75は、1を100等分した75個分でもあるので75%です。%は「100分のいくつ」を表します。

四則演算は足す・引く・掛ける・割る操作です。掛け算と割り算は足し算と引き算より先に行い、括弧の中をさらに先に計算します。6+3×4=18ですが、(6+3)×4=36です。0で割る操作には通常の数の答えを定めません。

今日の新しい名前は、分母と分子です。数字の上下を取り違えたら、お菓子を分ける場面へ戻ります。

1・分けた量

800個のうち3/4は何個ですか。分母と分子の役割も説明してください。

解答と考え方を読む

4等分した一組は200個。その3組なので600個です。分母4が分ける数、分子3が使う組の数です。

2・順序を確認する

18−2×5と(18−2)×5を計算してください。

解答と考え方を読む

前者は18−10=8。後者は16×5=80です。括弧の有無で何を一組として扱うかが変わります。

次は分数を足す・掛けるへ進みます。第3章は「分ける→分数の計算→割合の変化→負の数→合算」の順です。

標準的な算数を独自の例で説明しています。OpenStax Prealgebraが復習資料です。
