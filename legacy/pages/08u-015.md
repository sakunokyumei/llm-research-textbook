# 08-15 演習

読む目安5〜10分／演習25〜50分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の15/16ページ。

このページの演習：「実行前に予想する」、「代入の意味」、「型の区別」、「研究の計算を実装する」、「エラーを直す」。

:::exercise 1・実行前に予想する
`print(2 + 3 * 4)`と`print((2 + 3) * 4)`の出力を予想し、動かしてください。
:::answer
14と20です。算数で学んだ優先順位と一致します。実行できたことだけでなく、予想と一致したかも記録します。
:::

:::exercise 2・代入の意味
`x=3`、次に`x=x+2`、最後に`print(x)`を実行するとどうなりますか。
:::answer
5です。二行目は古いxの値3へ2を足し、その結果5へxという名前を付け直します。数学の[方程式](reference.html#term-equation)x=x+2を解いているのではありません。
:::

:::exercise 3・型の区別
`"12" + "3"`と`int("12") + 3`の結果はどう違いますか。
:::answer
前者は文字列"123"、後者は整数15です。ファイルから読み込んだ数値は文字列であることがあるので、型の確認が必要です。
:::

:::exercise 4・研究の計算を実装する
正解58件、全体100件の正解率を計算して表示する三行のプログラムを書いてください。
:::answer
`correct = 58`、`total = 100`、`print(correct / total)`です。結果は0.58。百分率で表示するならさらに100を掛けます。
:::

:::exercise 5・エラーを直す
`print(score)`だけのファイルでNameErrorが出ました。原因と、最小の修正を書いてください。
:::answer
scoreという名前にまだ値を割り当てていません。前に`score = 0.8`を追加すれば表示できます。実際のプログラムでは値をどこで作るべきかを考えます。
:::
