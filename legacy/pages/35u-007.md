# 35-7 演習

読む目安5〜10分／演習25〜50分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の7/8ページ。

このページの演習：「来歴」、「重複の順序」、「FLOPsの概算」、「外挿」、「フィルタの副作用」。

:::exercise 1・来歴
外部データを研究へ使う前に残すべき記録を四つ挙げてください。
:::answer
入手元、版や取得時点、利用条件、加工・除外手順、ハッシュ、分割方法などです。再取得不能なデータは保存や配布可能性も確認します。
:::

:::exercise 2・重複の順序
同じ文章のコピーを別々にランダム分割してから重複除去すると、何が残り得ますか。
:::answer
分割をまたぐ重複が残り得ます。各分割内だけの除去では漏洩を防げないため、分割間も調べます。
:::

:::exercise 3・FLOPsの概算
N=10⁶、D=10⁸として6NDを計算してください。
:::answer
6×10¹⁴ FLOPsです。これは演算数の概算で、秒数にするには実効速度や通信等を考える必要があります。
:::

:::exercise 4・外挿
小さい二点だけに直線が合いました。1000倍の規模の予測を確実と言えますか。
:::answer
言えません。モデル選択の自由度、測定誤差、範囲外で関係が変わる可能性があります。複数点と保留した検証規模が必要です。
:::

:::exercise 5・フィルタの副作用
品質フィルタの後、日本語が90%、英語が20%除かれました。何を調べますか。
:::answer
規則が特定言語へ不利でないか、文字数・記号率等の基準が妥当か、誤除去された具体例を調べます。全体平均だけで判断しません。
:::
