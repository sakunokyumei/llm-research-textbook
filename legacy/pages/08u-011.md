# 08-11 ファイルを実行する

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の11/16ページ。

Windowsでは次の順番で進めます。文章を書くアプリをテキストエディターと呼びます。メモ帳でもこの練習ができます。

1. ファイルを探すアプリ（エクスプローラー）で、書き込み可能な場所に `study` フォルダを作ります。
2. メモ帳へ、下の三行だけを入力します。
3. 「名前を付けて保存」でstudyフォルダを選びます。ファイルの種類を「すべてのファイル」にし、名前を `first.py` にします。
4. エクスプローラーでファイル名の末尾を確認します。末尾の種類を示す部分が拡張子で、Pythonのファイルは `.py` です。`.py.txt` になったら保存し直します。
5. エクスプローラーのアドレス欄からstudyフォルダの場所をコピーします。この場所を示す文字列がパスです。
6. PowerShellを開き、`cd "ここをコピーした場所に置き換える"` と入力します。`cd` は作業場所を変える命令です。引用符は残し、中身を実際の場所に置き換えます。
7. `dir` と入力して一覧に `first.py` があることを確認し、`python first.py` を実行します。先の確認で `py` を使った場合は `py first.py` です。

macOSやLinuxでも、保存後にターミナルで `cd "保存先の場所"`、`ls` で一覧を確認します。Pythonの起動名が `python3` なら、バージョン確認と実行の両方を `python3` に読み替えます。

```python
correct = 80
total = 100
print(correct / total)
```

出力は`0.8`です。`print(...)`は括弧内の結果を画面へ出す関数です。`=`は、右側の値へ左側の名前を付ける[代入](reference.html#term-substitution)です。数学の「左右が等しいという条件」とは異なります。等しいかを調べるPythonの記号は`==`です。

> 小例へ戻る：計算機へ処理を頼む文章がプログラム、Pythonはその文章を書く言語の一つです。print(2+3)は5を表示します。人へ向けた日本語の説明とは書き方が違います。

`correct = 90`に変えて再実行すると0.9になります。変数とは、値を参照するために付ける名前です。同じ名前へ別の値を割り当てることもできます。

> 小例へ戻る：cdは作業するフォルダを変える指示、printは値を表示するPythonの処理です。変数は値へ付ける名前で、price=100の後にprint(price)なら100を表示します。
