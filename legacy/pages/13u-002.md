# 13-2 SQL・SELECT・FROM

今回取り組むこと：取り出す列と元の表を指定する。

今回の用語をまとめて復習：[SQL・SELECT・FROM](beginner-glossary.html#concept-13u-002)。

## なぜ使うか

データ量に応じて処理方法を選び、集計するための一歩です。このページでは、取り出す列と元の表を指定することを練習します。

## 意味と小さな例

表へ問い合わせる言語がSQL。SELECTは取り出す値、FROMは元の表を指定します。SELECT price FROM itemsならitemsのprice列を読む指示です。まず二行の表を紙に描きます。

:::check 取り出す列と元の表を指定する
items表のname列だけを読むSELECT文を書いてください。
:::answer
SELECT name FROM itemsです。SELECTの後が取り出す列、FROMの後が表です。行を選ぶ条件は別に指定します。
:::
