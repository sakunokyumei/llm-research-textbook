# 50-8 対応を保つ

読む目安5〜10分／演習20〜40分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の8/10ページ。

このページの演習：「judgeの順序依存」、「保留の代償」、「多重比較」、「汚染の証明」。

同じ100問でAが80問、Bが75問正解しても、差の不確実性は合計だけでは分かりません。Aだけ正解した数とBだけ正解した数が重要です。[paired bootstrap](downloads/paired_bootstrap.py)は同じ文書のA/Bの結果を一緒に引き直します。文書中のtokenを独立標本と見なすと不確実性を小さく見積もることがあります。

:::exercise 1・judgeの順序依存
同じ答えを左右入れ替えると、先頭を選ぶ割合が70%でした。どう解釈しますか。
:::answer
提示順序が採点に影響している可能性があります。内容への選好と分離するため、反転して平均する、同点扱いの規則を定める、人手確認する等を行います。
:::

:::exercise 2・保留の代償
100問中40問に回答し36問正解。回答部分の正解率とcoverageは？
:::answer
90%と40%。全問回答のモデルの正解率と90%だけを比べてはいけません。
:::

:::exercise 3・多重比較
有意差がない20案をそれぞれ5%水準で試すと何が問題ですか。
:::answer
各検定の条件が満たされても偽陽性が増えます。独立なら少なくとも一つの偽陽性の確率は1−0.95²⁰≈64%。事前の主仮説、補正、独立な確認実験を用います。
:::

:::exercise 4・汚染の証明
評価問題が検索で見つかりませんでした。「汚染なし」と言えますか。
:::answer
言えません。検索範囲・検出方法の限界があります。「この照合手順では一致を検出しなかった」と範囲を明示します。
:::
