# 53-3 Error Analysis

読む目安5〜10分／確認5〜10分。時間は編集上の目安です。

この章の3/8ページ。

今回取り組むこと：誤答を全件分類する。

今回の用語をまとめて復習：[Error Analysis](beginner-glossary.html#concept-53u-003)。

## なぜ使うか

反証可能な仮説・対照条件・採点規則を実験前に固定するための一歩です。このページでは、誤答を全件分類することを練習します。

## 意味と小さな例

誤りを分類して原因候補を調べます。十問中四誤答なら「根拠なし二件、計算一件、指定違反一件」と全件を残します。よい例だけ選ぶ分析とは区別します。

:::check 誤答を全件分類する
誤答6件のうち根拠不足3、計算2、形式違反1でした。割合を求め、成功例だけを報告する場合との違いを述べてください。
:::answer
それぞれ1/2、1/3、1/6です。全誤答を残すと弱点の内訳を検討できます。見栄えの良い成功例だけでは分かりません。
:::
