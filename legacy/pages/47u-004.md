# 47-4 小さな状態を計算する

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の4/7ページ。

A=0.5、B=C=1、h₀=0、入力が2,0,4なら状態は2,1,4.5。過去の2は二回半減して0.5残ります。Aを固定すると、重要な語も不要な語も同じ規則で忘れます。Mambaでは入力に応じてSSMの一部のパラメータを変え、情報を選択します。高速なscan実装も核心です。単純なPythonループだけで同じ速度特性が得られるとは限りません。[Mamba原論文](https://arxiv.org/abs/2312.00752)

```python
state = 0.0
for value in [2, 0, 4]:
    state = 0.5 * state + value
    print(state)
```
