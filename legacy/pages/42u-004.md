# 42-4 Tensor Parallel・Pipeline Parallel・Context Parallel

今回取り組むこと：何を分けた並列化か判定する。

今回の用語をまとめて復習：[Tensor Parallel・Pipeline Parallel・Context Parallel](beginner-glossary.html#concept-42u-004)。

## なぜ使うか

分ける対象と通信の意味を区別し、実効バッチを計算するための一歩です。このページでは、何を分けた並列化か判定することを練習します。

## 意味と小さな例

行列演算、層のまとまり、長い列の位置をそれぞれ分ける方式です。四層の前二つと後二つを別装置へ置くならPipeline Parallel。分ける対象を図で指してから時間と通信を考えます。

:::check 何を分けた並列化か判定する
六層の前半三層を装置A、後半三層を装置Bへ置きました。どの並列化の例ですか。
:::answer
Pipeline Parallelです。層のまとまりを分けています。同じ層の行列演算を分けるTensor Parallelとは区別します。
:::
