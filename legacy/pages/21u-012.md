# 21-12 一緒に動くかを測る

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の12/14ページ。

共分散は`E[(X−E[X])(Y−E[Y])]`。二つが一緒に増えやすいなら正、逆なら負になりやすいです。標準偏差で割った相関[係数](reference.html#term-coefficient)は単位の影響を除きます。相関は因果関係を証明しません。共通する第三の要因が両方を動かす場合もあります。また相関0でも非線形の依存関係はあり得ます。

```python
import numpy as np
x = np.array([1., 2., 3.])
print(x.mean())
print(x.var(ddof=0))
print(x.var(ddof=1))
```

平均2、記述的な分散2/3、n−1で割った分散1になります。NumPyではddofという引数で分母n−ddofを指定します。
