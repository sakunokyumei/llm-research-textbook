## 数の向きと、行・列を決める

紙に数2と3を縦に並べると、2行1列の表になります。この縦一列に置いた[ベクトル](reference.html#term-vector)が**[列ベクトル](reference.html#term-column-vector)**です。横一行なら行ベクトル。`(2,3)`は数の並びの略記で、掛け算をするときは縦・横の約束を明記します。列ベクトルへ戻れます。

|縦に置いたx|値|
|---|---|
|上の成分|2|
|下の成分|3|

入力x=(2,3)から、出力の一つ目を2x₁+x₂、二つ目を−x₁+3x₂にしたいとします。それぞれ[内積](reference.html#term-dot)です。第5章で学んだ[係数](reference.html#term-coefficient)を二行に並べたA=[[2,1],[-1,3]]を使うと、二つの計算を`y=Ax`とまとめられます。結果は(7,7)です。

[行列](reference.html#term-matrix)は数を行と列に並べたものです。Aは2行2列。形を(2,2)と書きます。一般にAがm行n列、xがn個の列ベクトルなら、Axはm個の列ベクトルです。内側のnが一致している必要があります。

:::exercise 1・行列とベクトル
[[2,0],[1,3]]に列ベクトル(4,2)を掛けてください。
:::answer
第一成分2×4+0×2=8、第二成分1×4+3×2=10なので(8,10)です。
:::

## 四つの出力を一つずつ求める

A=[[1,2],[3,4]]、B=[[5,6],[7,8]]とします。ABの左上は、Aの最初の行とBの最初の列の[内積](reference.html#term-dot)なので1×5+2×7=19。同様に右上22、左下43、右下50です。各要素を単に掛ける計算とは違います。

`(AB)ᵢⱼ=Σₖ Aᵢₖ Bₖⱼ`と書けます。iは出力の行、jは出力の列、kは足し合わせる方向です。Aが(m,n)、Bが(n,p)ならABは(m,p)。一般にはABとBAは同じにならず、片方しか計算できない場合もあります。

:::exercise 2・形
(3,4)の[行列](reference.html#term-matrix)と(4,7)の行列の積の形は何ですか。逆順も可能ですか。
:::answer
(3,7)です。逆順は内側が7と3で一致しないため計算できません。
:::

:::exercise 3・交換できない例
A=[[1,1],[0,1]]、B=[[2,0],[0,3]]のABとBAを求めてください。
:::answer
AB=[[2,3],[0,3]]、BA=[[2,2],[0,3]]です。右上が違い、変換の順序に意味があると分かります。
:::

## 一行を一列へ移す

[転置](reference.html#term-transpose)Aᵀは行と列を交換します。形(m,n)は(n,m)へ変わります。転置は数の並び順を交換する操作で、各値そのものを変える操作ではありません。

|元のAの行|値|
|---|---|
|1行目|1, 2, 3|
|2行目|4, 5, 6|

転置後は三行になり、一行目(1,4)、二行目(2,5)、三行目(3,6)です。元の一行を、転置後の一列へ移しました。文章中の情報同士を比べる応用は[第31章](31-attention.html)で学びます。今は転置の操作だけを確認します。

:::exercise 4・転置を表へ戻す
A=[[1,2],[3,4],[5,6]]の形とAᵀの形・全要素を書いてください。
:::answer
Aは(3,2)、Aᵀは(2,3)で[[1,3,5],[2,4,6]]です。
:::

## 二つの方向で全部を作れるか

二次元の[ベクトル](reference.html#term-vector)は、横へ一つ進む(1,0)と縦へ一つ進む(0,1)を掛けたり足したりして表せます。(2,3)=2(1,0)+3(0,1)です。このように数を掛けて足す組合せを[線形結合](reference.html#term-basis)と呼びます。

どのベクトルも作れ、かつ一つの方向をほかの方向の組合せでは作れない基本方向の組が**基底**です。その本数が次元です。(1,2)と(2,4)なら後者は前者の2倍で、一方向分しかありません。このようにほかの列で作れない独立な列の最大数が**[ランク](reference.html#term-rank)**です。基底・ランクへ戻れます。

:::exercise 5・独立な方向
(1,2)と(2,4)は二次元全体の基底になりますか。
:::answer
なりません。後者は前者の2倍で同じ直線上にあり、二つを組み合わせてもその直線以外へ進めません。
:::

## 同じ条件を表と式で書く

`x+y=5`、`x−y=1`を足すと2x=6なのでx=3、y=2です。これもAx=bという[行列](reference.html#term-matrix)の形にできます。逆行列は変換を元に戻す行列ですが、すべての行列に存在するわけではありません。二行が同じなら、二つの独立な条件がありません。数値計算では逆行列を明示的に作るより、連立[方程式](reference.html#term-equation)を解く専用関数を使います。

NumPyは数の配列を扱う[ライブラリ](reference.html#term-library)です。準備がまだなら[第12章](12-environment.html)へ戻ってください。`import numpy as np`はNumPyをnpという短い名前で使う指定、`np.array`は数の並びから計算用の配列を作る操作です。

```python
import numpy as np
A = np.array([[1., 1.], [1., -1.]])
b = np.array([5., 1.])
x = np.linalg.solve(A, b)
print(x)
print(A @ x)
```

NumPyは数の配列を扱うライブラリです。未導入なら[第12章の仮想環境とインストール手順](12-environment.html)へ戻ります。`@`は行列積で、`*`は要素ごとの積です。出力は[3,2]と[5,1]になります。

:::exercise 6・方程式
2x+y=7、x−y=2を解いてください。
:::answer
二式を足して3x=9、x=3。x−y=2からy=1。元の両式へ[代入](reference.html#term-substitution)して確認できます。
:::
