# 25 回帰・分類を自分で学習する：まとめて参照

長い参照ページです。初めて学ぶときは[小ページの順序](25-regression.html)を使い、ここへ戻って式やコードを引けます。


## 規則を数で調整する

入力xから数yを予測したいとします。まず`ŷ=wx+b`という直線を使います。ŷは予測値、wは傾き、bは切片です。正解yとのずれを二乗し、その平均を小さくします。二乗は大きな誤差を強く罰し、正負の打ち消しを防ぎます。

`L=(1/n)Σᵢ( wxᵢ+b−yᵢ )²`とすると、wへの[微分](reference.html#term-derivative)は`(2/n)Σᵢ(ŷᵢ−yᵢ)xᵢ`、bへの微分は`(2/n)Σᵢ(ŷᵢ−yᵢ)`。[連鎖律](reference.html#term-chain-rule)で二乗の外側と直線の内側をたどっています。

コードの `w -= lr * dw` は、今回の数値では `w = w - lr * dw`、bも同様です。[第19章の加算代入](19-integration.html)の引き算版です。まず一例の誤差を求め、微分を掛け、歩幅lrで一回だけ更新してから300回へ進みます。

```python
xs, ys = [0., 1., 2.], [1., 3., 5.]
w, b, lr = 0., 0., 0.1
for step in range(300):
    errors = [w * x + b - y for x, y in zip(xs, ys)]
    dw = 2 * sum(e * x for e, x in zip(errors, xs)) / len(xs)
    db = 2 * sum(errors) / len(xs)
    w -= lr * dw
    b -= lr * db
print(w, b)
```

wは約2、bは約1へ近づきます。データがちょうど直線上にある玩具例です。現実のデータは雑音があり、学習例へ完全に一致させることが目的とは限りません。

## 数を予測するか、クラスを予測するか

二択の確率を出すなら、直線の出力z=wx+bをシグモイド`σ(z)=1/(1+exp(−z))`へ通します。結果は0から1の範囲です。これを使うロジスティック回帰は、名前に回帰とありますが二値分類にも使う基本モデルです。

正解yが0か1なら、二値交差[エントロピー](reference.html#term-entropy)は`−y ln p −(1−y)ln(1−p)`です。zで微分するとp−yとなります。モデルが正解1へ低い確率を付けたとき、この[勾配](reference.html#term-gradient)を通じてzを増やす向きへ更新できます。実装では確率へ変換してからlogを取るより、logitから直接計算する安定な関数を使います。

logit（ロジット）は、ここでは確率へ変換する前の点数zです。二択では `p=σ(z)` により確率へ変わります。z=0の点数とp=0.5の確率を同じ値として扱わないでください。

## 他の基準モデルも知る

決定木は「xが閾値以上か」のような条件で分割し、葉で予測します。多数の木を組み合わせるensembleには、異なる標本で木を作るRandom Forestや、残った誤差を順に補うboostingがあります。表形式データでは深層学習だけを唯一の選択肢にしません。

正解ラベルなしに似た入力をまとめるclusteringもあります。k-meansは点をk個の中心へ割り当て、中心までの二乗距離を減らします。kや尺度、初期値に依存し、人間にとって意味のある群になる保証はありません。PCAは中心化したデータの[分散](reference.html#term-variance)が大きい方向へ射影する方法で、[SVD](reference.html#term-svd)と関係します。ラベルに重要な方向が必ず大分散とは限りません。

## 演習

:::exercise 1・一例の勾配
x=2、y=5、w=1、b=0で二乗誤差を使います。予測・誤差・dw・dbを求めてください。
:::answer
予測2、誤差−3、dw=2×(−3)×2=−12、db=2×(−3)=−6です。
:::

:::exercise 2・一回の更新
前問で[学習率](reference.html#term-learning-rate)0.1なら新しいwとbはいくつですか。
:::answer
w=1−0.1×(−12)=2.2、b=0.6。この一点の新しい予測は5で[損失](reference.html#term-loss)0ですが、別の入力でも正しいかは分かりません。
:::

:::exercise 3・シグモイド
z=0ならσ(z)はいくつですか。zを増やすとどうなりますか。
:::answer
1/(1+1)=0.5。zを増やすと1へ近づきます。
:::

:::exercise 4・分類の勾配
正解y=1、予測p=0.2ならlogitに対する交差エントロピーの勾配はいくつですか。
:::answer
p−y=−0.8。負の勾配を引く更新はlogitを増やす方向です。
:::

:::exercise 5・clusteringの限界
k-meansへ年齢と年収をそのまま入れると、どんな問題があり得ますか。
:::answer
尺度が大きく異なり、年収の数値が距離を支配する場合があります。標準化や距離の設計を検討します。標準化の統計は学習側だけで推定します。
:::

## 到達課題と出典

回帰のコードで学習率を0.01、0.1、1へ変え、損失の推移と失敗を記録してください。良い値だけを残さないことが基準です。[scikit-learn Linear models](https://scikit-learn.org/stable/modules/linear_model.html)、[Clustering](https://scikit-learn.org/stable/modules/clustering.html) を参照。
