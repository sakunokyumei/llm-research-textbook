# 39-11 比較する四つのモデルを図にする

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の11/13ページ。

`prompt → 学習中の方策 → 応答 → 報酬` を描き、固定した参照方策を横へ置きます。旧方策は更新の前にその応答を作った方策、参照方策は離れすぎを測る固定の基準です。同じになる時点があっても役割は別です。value modelは「この状況からどれくらいの収益が見込めるか」を予測するモデルで、第38章のbaselineを学ぶ役割を持てます。

PPOのminは二値の小さい方、clipは第28章の範囲への切り詰めです。DPOのσは第25章のシグモイド。GRPOで報酬 `[0,1,1]` から平均2/3を引くなら、相対値は `[-2/3,1/3,1/3]`。ここでは[標準偏差](reference.html#term-variance)による追加の正規化をしていません。標準化する版との違いを明記します。オンラインは今の方策で新しい応答を作って学習すること、オフラインは用意されたデータを使うことです。

四列表を作れなければ、[第36章のSFT](36-adaptation.html)・[第38章の方策とbaseline](38-reinforcement.html)へ戻り、誰がデータを作り誰を更新するかを一つずつ確認します。
