# 09-6 人が毎回判断しなくてよいように

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の6/10ページ。

点数が合格基準以上か、100件の答えが正しいか。コンピュータに任せたい作業には、判断と繰り返しが含まれます。`if`は条件で処理を分け、`for`は複数の値に対して処理を繰り返します。

```python
score = 75
if score >= 60:
    print("合格")
else:
    print("もう一度練習")

for value in [2, 4, 6]:
    print(value * 2)
```

出力は「合格」、4、8、12です。`>=`は以上、`[]`で囲んだ値の並びはリストです。コロンの次に続く行は空白4個分だけ下げます。この字下げ、つまり[インデント](reference.html#term-indent)が同じ処理のまとまりを示します。見た目だけの飾りではありません。

> 小例へ戻る：リスト[2,4,6]は順序のある並びです。forで一つずつ取り出します。字下げのインデントで繰り返す処理をまとめます。合計は0→2→6→12と変わります。
