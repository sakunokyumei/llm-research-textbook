# 11-8 大きな失敗を小さくする

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の8/10ページ。

たとえば100件の平均がおかしいとき、まずデータを二件に減らします。入力・出力・形・値の範囲を表示し、手計算と比べます。原因候補を五つ同時に変えると、どの変更が効いたか分からなくなります。一つずつ変更し、同じテストを再実行します。

関数を別ファイルへ分けると、そのファイルを[モジュール](reference.html#term-module)としてimportできます。関連した状態と操作をまとめるときは[クラス](reference.html#term-class)を使います。たとえば次のCounterは、countという状態とaddという操作を持ちます。

```python
class Counter:
    def __init__(self):
        self.count = 0

    def add(self):
        self.count = self.count + 1

counter = Counter()
counter.add()
print(counter.count)
```

selfは「この実体」を参照する名前です。`__init__`は実体を作る際の初期化処理。後で使うPyTorchは、数値計算やモデル作成を助ける道具の集まりです。そのモデルもこの考えで作るので、状態を持つ関数のまとまりとして理解しておきます。
