# 22-4 復元抽出・paired bootstrap

今回の用語をまとめて復習：[復元抽出・paired bootstrap](beginner-glossary.html#concept-22u-004)。

## なぜ使うか

データと学習の揺れを区別して、差の不確かさを報告するための一歩です。このページでは、対応を保って引き直すことを練習します。

## 意味と小さな例

同じ項目を何回も選べる抽出が復元抽出。同じ問題番号で二手法を一緒に引き直すのがpaired bootstrapです。差[1,0,−1]を番号[0,0,1]で選べば[1,1,0]、平均2/3。二手法を別々の番号で選びません。

:::check 対応を保って引き直す
手法間の差[2,−1,3]を番号[2,0,2]で復元抽出すると、どの並びと平均になりますか。
:::answer
[3,2,3]で平均8/3です。同じ番号を二度使えます。二手法を別々の番号で引くと元の問題ごとの対応を壊します。
:::
