# 35 データを作り、規模を見積もる：まとめて参照

長い参照ページです。初めて学ぶときは[小ページの順序](35-data-scaling.html)を使い、ここへ戻って式やコードを引けます。


## 多ければ何でもよいのか

同じ文章を百回追加すると、ファイルは百倍になりますが新しい情報が百倍になるわけではありません。モデルはデータの質、重複、分野の偏り、学習量の影響を受けます。[事前学習](reference.html#term-pretrain)の設計では「何[トークン](reference.html#term-token)か」の前に「何を、どの条件で使うか」を決めます。

データの入口で、入手元、取得時点、版、利用条件、加工方法を記録します。公開Web上にあることと、無制限な再利用が認められることは同じではありません。個人情報を学習へ混ぜない設計、不要な情報の削減、削除要求への対応も考えます。具体的な法的判断は適用地域と契約に依存するため、ここでは一律の合法・違法を断定しません。

## Pipelineを段階に分ける

収集、形式の統一、本文抽出、品質フィルタ、重複除去、分割、混合比の設定、トークン化、packingという段階に分けます。各段階で件数と除外理由を数えます。強いフィルタはノイズだけでなく少数言語や特定の文体も落とし得るため、サンプルを読み、言語・分野別の残存率を確認します。

完全一致重複はハッシュ等で検出できますが、近重複には別の方法が必要です。最終評価セットに似た文章が学習側へ入っていないかも調べます。文字列が一致しないだけで汚染がないとは言えません。

packingは短い文章をまとめて空き領域を減らす方法です。文書間を見せる設計か、block diagonalなmaskで分離する設計かを決め、EOS、position、[損失](reference.html#term-loss)対象を一致させます。「つなげれば同じ」というわけではありません。

## Scaling lawは経験則

モデル規模N、学習トークン数Dなどと損失の関係を、測定した範囲で関数に当てはめるのがscaling lawの研究です。例として`L≈E+A/N^α+B/D^β`のような形を考えます。[係数](reference.html#term-coefficient)や[指数](reference.html#term-power)はデータ・構造・学習方法に依存し、自然法則として全範囲へ保証されるものではありません。

密なTransformerの学習FLOPsをおおまかに6NDと見積もる近似は、仮定を置いた資源会計の目安です。[Attention](reference.html#term-attention)の系列長依存、[Embedding](reference.html#term-embedding)、実装、再計算などを精密に扱った式ではありません。小規模な複数点を測り、当てはめに使わなかった規模で予測を検証します。

## 自作の四文書で処理の順番を確認する

pipelineは、入力から出力へ処理を段階的につなぐ流れです。品質フィルタは用途に合わない文書を除く規則で、packingは長さの違う文書を一つの列へ詰める操作です。block diagonalなmaskは、同じ文書の範囲内だけを見られる表。二文書が各2位置なら、左上2×2と右下2×2を許し、文書をまたぐ右上・左下を隠します。

この確認ではまだpackingせず、空文書と完全一致の重複だけを除きます。

```python
docs = ["猫が寝る", "", "猫が寝る", "犬が走る"]
nonempty = []
for doc in docs:
    if doc.strip():
        nonempty.append(doc)
unique = []
seen = set()
for doc in nonempty:
    if doc not in seen:
        seen.add(doc)
        unique.append(doc)
print(len(docs), len(nonempty), len(unique))
```

件数は4→3→2。`if doc.strip()` は空白を除いた文字列が空でなければ進むという条件です。空文字は条件としてFalse、空でない文字列はTrueです。除いた理由と件数を別に記録し、train/validation/testへ分ける前に一致を調べます。近い言い換えの除去まではこのコードでできません。FLOPsは[浮動小数点](reference.html#term-finite)の演算回数で、秒数ではありません。[第13章の集合](13-algorithms.html)、[第24章の分割](24-learning.html)へ戻れます。

## 演習

:::exercise 1・来歴
外部データを研究へ使う前に残すべき記録を四つ挙げてください。
:::answer
入手元、版や取得時点、利用条件、加工・除外手順、ハッシュ、分割方法などです。再取得不能なデータは保存や配布可能性も確認します。
:::

:::exercise 2・重複の順序
同じ文章のコピーを別々にランダム分割してから重複除去すると、何が残り得ますか。
:::answer
分割をまたぐ重複が残り得ます。各分割内だけの除去では漏洩を防げないため、分割間も調べます。
:::

:::exercise 3・FLOPsの概算
N=10⁶、D=10⁸として6NDを計算してください。
:::answer
6×10¹⁴ FLOPsです。これは演算数の概算で、秒数にするには実効速度や通信等を考える必要があります。
:::

:::exercise 4・外挿
小さい二点だけに直線が合いました。1000倍の規模の予測を確実と言えますか。
:::answer
言えません。モデル選択の自由度、測定誤差、範囲外で関係が変わる可能性があります。複数点と保留した検証規模が必要です。
:::

:::exercise 5・フィルタの副作用
品質フィルタの後、日本語が90%、英語が20%除かれました。何を調べますか。
:::answer
規則が特定言語へ不利でないか、文字数・記号率等の基準が妥当か、誤除去された具体例を調べます。全体平均だけで判断しません。
:::
