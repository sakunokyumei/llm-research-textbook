## 記号を読む前に、小例へ戻る

回数を数えるrange(3)は0,1,2を作ります。whileは条件が成り立つ間繰り返します。回数を増やす操作を忘れると終わらないことがあるので、まず三回だけ紙で追います。

```python
total = 0
for value in [2, 4, 6]:
    total = total + value
print(total)
```

最初にtotalは0。1回目に2、2回目に6、3回目に12になります。最後のprintは字下げされていないので、ループが終わった後に一度だけ実行されます。

`range(3)`は0,1,2という三つの整数を順に使うための仕組みです。3を含みません。`while`は条件が真の間繰り返します。終了条件を変え忘れると終わらなくなるので、回数が決まる場合はforから始めましょう。
