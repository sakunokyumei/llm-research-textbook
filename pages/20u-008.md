# 20-8 追加の確認問題

読む目安5〜10分／演習30〜60分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の8/9ページ。

このページの演習：「同様に確からしいか」、「条件の反転」、「戻さず引く」、「確率の連鎖」、「組合せ」、「事前確率」。

:::exercise 2・同様に確からしいか
公平な六面サイコロで偶数が出る確率は何ですか。
:::answer
2,4,6の3通りを全6通りで割って1/2です。公平という条件を使っています。
:::

:::exercise 3・条件の反転
上のメールの例で、普通のメールに「無料」がある確率はいくつですか。
:::answer
8/80=0.1です。一方、無料があるメールのうち普通なのは8/24=1/3。条件の順序で分母が違います。
:::

:::exercise 4・戻さず引く
赤2個、青1個の袋から二回戻さず引くとき、二回とも赤の確率はいくつですか。
:::answer
最初の赤は2/3、赤を一つ取った後の赤は1/2。積は1/3です。独立と誤って(2/3)²にしないでください。
:::

:::exercise 5・確率の連鎖
P(a)=0.4、P(b|a)=0.5、P(c|a,b)=0.2なら、列abcの確率は何ですか。
:::answer
0.4×0.5×0.2=0.04。条件付き確率を順に掛けています。
:::

:::exercise 6・組合せ
四つの設定A,B,C,Dから異なる二つを順序なしで選ぶ組を列挙してください。
:::answer
AB,AC,AD,BC,BD,CDの6通りです。4×3=12は順序付きの数なので、二重計数を2で割ります。
:::

:::exercise 7・事前確率
「検出器が高精度だから陽性なら必ず本物」と断定できないのはなぜですか。
:::answer
陽性の中には誤検出も含まれ、対象の事前確率にも依存するためです。メールのように真陽性と偽陽性の[実数](reference.html#term-real)を並べて考えると分かります。
:::
