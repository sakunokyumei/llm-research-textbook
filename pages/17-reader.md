## 時間幅を小さくする

<figure class="learning-figure"><svg viewBox="0 0 360 210" role="img" aria-labelledby="slope-title"><title id="slope-title">時間幅を狭めて、傾きを調べる</title><path d="M35 175 H325 M35 175 V15" fill="none" stroke="currentColor"/><path d="M35 175 Q175 170 290 35" fill="none" stroke="#245da8" stroke-width="3"/><path d="M174 135 L290 35 M174 135 L210 111" fill="none" stroke="#a56630" stroke-width="2"/><g fill="#245da8"><circle cx="174" cy="135" r="5"/><circle cx="210" cy="111" r="5"/><circle cx="290" cy="35" r="5"/></g><g font-size="14" fill="currentColor"><text x="170" y="195">2</text><text x="274" y="195">3</text><text x="310" y="195">時間</text><text x="42" y="23">位置</text><text x="220" y="130">近い二点で比べる</text></g></svg><figcaption>図は時間幅を狭める概念図です。正確な平均変化率5、4.1、4.01は本文の数値から計算します。</figcaption></figure>

車が2時間で100km進めば平均速度は50km/hです。しかし途中で止まったかもしれません。今この瞬間の速度を知るには、見る時間幅を短くしていきます。この発想が[微分](reference.html#term-derivative)です。

位置をf(t)=t²とする模型で、t=2からt=3の平均変化率は(9−4)/(3−2)=5。t=2から2.1では(4.41−4)/0.1=4.1。幅hを使って書くと、`((2+h)²−2²)/h=4+h`です。hを0に近づけると4へ近づきます。この値をt=2の微分[係数](reference.html#term-coefficient)と呼びます。

h=0を直接[代入](reference.html#term-substitution)すると0/0になってしまいます。「0を代入する」のではなく「0へ近づくとどの値へ近づくか」を考えるのが極限です。記号limで表します。関数全体について微分係数を返す新しい関数を導関数と呼び、f'(t)と書きます。

:::exercise 1・平均変化率
f(x)=x²のx=1からx=3までの平均変化率を求めてください。
:::answer
(9−1)/(3−1)=4です。x=1の瞬間の傾き2とは異なります。
:::

:::exercise 2・差分から導く
f(x)=3x+2について、(f(x+h)−f(x))/hを整理してください。
:::answer
(3x+3h+2−3x−2)/h=3。hが0でない限り一定なので、微分係数も3です。
:::

## 数値の例から一般式へ

同じ計算をxで行うと、`((x+h)²−x²)/h=2x+h`。したがってf(x)=x²の導関数はf'(x)=2xです。二乗の[微分](reference.html#term-derivative)が2xになる理由は、単なる暗記ではなくこの差分から説明できます。

基本的な規則として、定数の微分は0、xのn乗はn xⁿ⁻¹、和は微分の和です。[exp](reference.html#term-log)(x)の微分はexp(x)、ln(x)の微分は1/x（x>0）。積は`(fg)'=f'g+fg'`となり、f'g'ではありません。公式には[定義域](reference.html#term-domain)や微分可能性の条件があります。

|関数|導関数|例|
|---|---|---|
|3|0|入力を変えても一定|
|3x+2|3|傾きが常に3|
|x²|2x|x=−1なら傾き−2|
|x³|3x²|x=2なら傾き12|

自然対数lnやexpを保留していたら、[第7章の意味](07-logarithms.html)・用語集へ戻れます。まず定数・直線・二乗の三つを確認し、[指数](reference.html#term-power)関数の微分は別の回へ分けてください。

:::exercise 3・導関数
f(x)=2x³−4x+7の導関数と、x=2での値を求めてください。
:::answer
f'(x)=6x²−4、x=2では24−4=20です。
:::

:::exercise 4・積の微分
x×xの微分を積の公式で求めてください。
:::answer
1×x+x×1=2xです。各微分の積1×1=1ではありません。
:::

## 左右で傾きが違う点

絶対値|x|は0で尖っています。左からの傾きは−1、右からは1なので、一つの傾きに決まりません。すべての関数がすべての点で[微分](reference.html#term-derivative)できるわけではありません。[機械学習](reference.html#term-ml)の[ライブラリ](reference.html#term-library)がそこで特定の値を返すことは、数学的な微分が存在することとは別です。

```python
def f(x):
    return x * x

x = 2.0
for h in [0.1, 0.01, 0.001]:
    print(h, (f(x + h) - f(x)) / h)
```

結果は約4.1、4.01、4.001です。hを無限に小さくすれば実装も無限に正確になるわけではありません。[有限精度](reference.html#term-finite)の引き算では、近い数の差が不正確になる場合があります。

:::exercise 5・傾きの符号
f(x)=x²のx=−2では、xを少し増やすと値は増えますか。
:::answer
傾き2x=−4なので局所的には減ります。実際にf(−2)=4、f(−1.9)=3.61です。
:::

:::exercise 6・極限と実装
差分でh=0をそのまま使ってよいですか。また小さくし続ければ必ず精度が上がりますか。
:::answer
h=0では分母が0になるため使えません。小さすぎるhでは浮動小数点の丸めや桁落ちにより精度が悪化し得ます。式としての極限と数値近似を分けます。
:::

## 小さい差が消えるとは

浮動小数点は、有限の桁数で数を近似して保存する方式です。たとえば小数一桁しか残せない機械なら、1.001も1.000も1.0になり、差が0に見えてしまいます。実際のPythonはこの十進一桁方式ではありませんが、近い二つの近似値を引くと有効な桁が失われる「桁落ち」の動機は同じです。[第4章の丸め](04e-errors.html)へ戻り、数式の極限と保存できる精度を分けましょう。形式の比較は[第28章](28-numerics.html)で扱います。
