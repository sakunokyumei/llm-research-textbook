# 47-6 比較表を自分で作る

読む目安10〜20分／確認5〜10分。長いコードの実行はPCを使える別の回へ分けられます。時間は編集上の目安です。

この章の6/7ページ。今日の目標：比較表を自分で作るの小例を一つ追う。

## 記号を読む前に、小例へ戻る

入力に応じた選択を使うSSM系統がMamba。隠した離散単位を反復して直す系統がmask型拡散。複数の仕組みを組み合わせるのがhybridです。一回の次単位予測と、三回の修正を比較するなら回数と費用もそろえます。

|方式|記憶するもの|実験で調べる点|
|---|---|---|
|自己回帰Attention|位置ごとのKとV|文脈長に対する容量・遅延|
|再帰・SSM|更新される状態|遠くの情報を残せるか|
|hybrid|両方|層の配置と計算量の交換関係|
|mask型拡散|更新中の系列|生成ステップ数と品質|

:::exercise 3・忘れる速さ
A=0.8、B=1、h₀=0、入力1,0,0を計算してください。
:::answer
h₁=1、h₂=0.8、h₃=0.64。初期の寄与はAの[累乗](reference.html#term-power)で減ります。
:::

:::exercise 4・固定容量の代償
状態が一定サイズなら、任意長の文章を完全に復元できますか。
:::answer
[有限精度](reference.html#term-finite)で表現できる状態数には限りがあります。任意の文章を損失なく保存する保証はありません。課題に必要な情報を残せるかを測ります。
:::

:::exercise 5・速度比較
拡散モデルが8回、自己回帰モデルが128回ネットワークを呼びました。16倍高速ですか。
:::answer
断定できません。各回で計算する位置数、cache、並列性、メモリ転送が異なります。実測の壁時計時間と品質を揃えます。
:::

:::exercise 6・研究への一歩
copy課題でSSMとAttentionを比較する独立変数と従属変数を挙げてください。
:::answer
独立変数は記憶方式と距離。従属変数はcopy正解率、時間、最大メモリなど。学習例数・seed・パラメータ数または計算予算を管理します。公平性の基準を先に決めます。
:::
