長い参照ページです。初めて学ぶときは[小ページの順序](22-statistics.html)を使い、ここへ戻って式やコードを引けます。


## 82点は80点よりよいと言えるか

二つのモデルを100問で比べ、一方が82問、もう一方が80問正解しました。差は2パーセントポイントです。しかし別の100問なら逆転するかもしれません。調べたい全体を母集団、実際に測った一部を標本と呼びます。標本から計算した平均や正解率は、標本の選び方により変わります。

[標準偏差](reference.html#term-variance)は個々の観測値の散らばり。標準誤差は、標本を取り直したときに推定量がどれほど揺れるかを表します。独立同分布で有限の分散を持つ標本の平均なら、標準誤差を`s/√n`で推定できます。sは標本標準偏差、nは件数です。文章が同じ著者や同じ文書に属する場合、独立という仮定が崩れることがあります。

中心[極限](reference.html#term-derivative)定理は、適切な条件で、多数の観測の和や平均を標準化した分布が正規分布に近づくことを述べます。元の観測自体が正規分布になる、あるいはnが決まった数を超えれば何でも安全、という意味ではありません。

## 区間を一本作ってから、繰り返す

先に、数を入れて一区間を作ります。ここだけは、観測が独立な正規分布、全体の標準偏差が既知で1、観測数4という模型です。平均の標準誤差は1/√4=0.5。この模型では平均の両側へ1.96×0.5=0.98を付ける方法が95%信頼区間になります。標準偏差を標本から推定する場合や非正規の小標本へ、そのまま使える式とは限りません。

標本が[49,50,50,51]なら平均50。区間は[49.02,50.98]です。両端を平均から0.98引く・足すという二操作で作りました。

真の平均が50と分かっている模型で、別の標本から得た平均を並べます。実際の研究では真値は分からないので、真値が既知の模型で手続きを練習します。

|標本の平均|作る区間|真値50を含むか|
|---|---|---|
|49.7|[48.72,50.68]|含む|
|50.3|[49.32,51.28]|含む|
|51.2|[50.22,52.18]|含まない|
|48.6|[47.62,49.58]|含まない|

この四行は手で確かめるための例で、2/4を95%の実証とは呼びません。多数の独立な標本へ同じ方法を繰り返したときの割合が95%という性質です。一本の区間を見た後に、固定された真値が95%の確率で動くという話ではありません。

:::exercise 1・区間を数字で作る
同じ模型で標本平均50.5なら両端はいくつですか。真値50を含みますか。
:::answer
50.5−0.98=49.52、50.5+0.98=51.48。真値50を含みます。一本については含む・含まないで、手続きの反復割合と区別します。
:::

[NIST：平均の信頼限界](https://www.itl.nist.gov/div898/handbook/eda/section3/eda352.htm)で仮定と区間作成を確認できます。前提が止まったら[平均と分散](21-distributions.html)へ戻ります。

## 信頼区間の読み方

95%信頼区間は、同じ方法で標本抽出と区間作成を繰り返したとき、区間が真の値を含む割合が95%になるような手続きです。頻度論の解釈では、観測後の固定された区間に真の値が95%の確率で入る、とそのまま言い換えません。Bayesの信用区間とは推論の枠組みが違います。

近似や仮定が悪いと名目上の95%と実際の被覆率はずれます。件数・推定方法・独立性の扱いを一緒に報告します。

## 同じ問題で差を測る

同じ問題に対する二手法の結果をペアとして保存すると、問題ごとの難しさを共有したまま差を測れます。paired [bootstrap](reference.html#term-bootstrap)は、問題IDを復元抽出し、その同じIDで両モデルを取り直して差を計算する方法です。復元抽出とは、同じ項目を何度でも選んでよい抽出です。

## まず三問を紙で引き直す

二手法の同じ問題の正誤を引き算して、差を `[1,0,-1]` とします。平均差は0。問題の番号 `[0,0,1]` を選び直せば差は `[1,1,0]`、平均2/3です。番号 `[2,1,2]` なら差は `[-1,0,-1]`、平均−2/3。**同じ番号で両手法を選ぶ**ので、Aだけ別の問題を引く方法とは違います。

|引き直すもの|一回分の例|その回の平均差|
|---|---|---|
|問題番号|0,0,1|2/3|
|問題番号|2,1,2|−2/3|

「乱数」は、くじのようなばらつきを模擬する数です。ここで使う生成器は計算手順で列を作る疑似乱数生成器。同じseedという開始設定を与えると、同じ生成器・版・呼び出し順なら同じ列を再現できます。暗号用の秘密を作る用途には使いません。

次のコードを一行ずつ読みます。

|記法|意味|
|---|---|
|`default_rng(42)`|seed 42から始める乱数生成器を作る|
|`integers(0,8,size=(2000,8))`|0〜7の番号を、2000回分×一回8問の表で作る。上限8は含まない|
|`diff[idx]`|番号の表の各位置に、対応する差を置く。形は(2000,8)|
|`mean(axis=1)`|各回の8問を平均し、2000個の平均差を作る|
|`quantile(boot,[0.025,0.975])`|平均差を小さい順に見た2.5%点と97.5%点を求める|

先に `np.array([1,0,-1])[np.array([[0,0,1],[2,1,2]])]` を紙で展開し、上の二行になるか確かめます。配列と軸は[第16章](16-tensors.html)、対応を引き算する考えは[第14章](14-vectors.html)へ戻れます。仕様は[NumPy integers](https://numpy.org/doc/stable/reference/random/generated/numpy.random.Generator.integers.html)・[整数配列による添字](https://numpy.org/doc/stable/user/basics.indexing.html#advanced-indexing)・[quantile](https://numpy.org/doc/stable/reference/generated/numpy.quantile.html)を参照します。

```python
import numpy as np
rng = np.random.default_rng(42)
a = np.array([1, 1, 0, 1, 0, 1, 1, 0])
b = np.array([1, 0, 0, 1, 1, 1, 0, 0])
diff = a - b
idx = rng.integers(0, len(diff), size=(2000, len(diff)))
boot = diff[idx].mean(axis=1)
print("observed difference", diff.mean())
print("percentile interval", np.quantile(boot, [0.025, 0.975]))
```

これは手順を学ぶ8問の玩具例です。信頼できる性能主張に十分な標本とは限りません。固定した予測への問題の再抽出は、学習seedを変えて訓練をやり直す変動とは別です。独立した学習を複数回行うなら、両方の不確かさを区別して報告します。

## 検定と効果量

帰無仮説を「差がない」とし、検定で使う他の仮定も満たされるとしたとき、観測した統計量以上に極端な値が生じる確率をp値と呼びます。統計量は、差などデータから計算する検定用の数です。「どちら向きの極端さを数えるか」も実験前に決めます。仮説が正しい確率ではありません。またp値が小さくても実用上の改善が小さい場合があり、大きくても「同等」が証明されたわけではありません。

効果量は差の大きさです。正解率の絶対差や、時間の比など、意味が伝わる量をまず示します。多くの仮説を試すほど偶然に小さなp値が見つかりやすくなるので、事前の主要仮説と探索的な分析を分け、多重比較への対応を考えます。

## 演習

:::exercise 2・標準誤差
標本標準偏差が10、独立な観測が100個あるとき、平均の標準誤差の推定値はいくつですか。
:::answer
10/√100=1です。標準偏差10と標準誤差1は測っている揺れが違います。
:::

:::exercise 3・標本を増やす
同じ分布で件数を4倍にすると、平均の標準誤差はおおむねどうなりますか。
:::answer
1/√4=1/2になります。独立同分布などの条件が同じという前提です。
:::

:::exercise 4・p値の誤読
p=0.03を「仮説が誤りである確率97%」と言ってよいですか。
:::answer
いけません。p値は帰無仮説のもとでのデータの極端さに関する確率です。仮説そのものの事後確率ではありません。
:::

:::exercise 5・再抽出の単位
一つの長文から100個の文を切り出して評価しました。文を独立な100件として扱う場合の問題は何ですか。
:::answer
同じ文書由来の文には相関があり得ます。独立性を過大に見積もって区間を狭くする恐れがあります。文書単位の抽出など、データ生成過程に合う単位を考えます。
:::

:::exercise 6・学習と評価の揺れ
一つのモデルの固定予測を10000回bootstrapすれば、10種類の学習seedを試した代わりになりますか。
:::answer
なりません。bootstrapは固定予測に対する評価標本の変動です。学習時の初期値やデータ順序によるモデルの変動を測っていません。
:::

:::exercise 7・非有意の結論
有意差が出なかったとき、結果をどう書きますか。
:::answer
観測した差、区間、件数、検定方法を示し、この実験では差を十分に確定できなかったと述べます。同等性の主張には許容差を定めた別の設計が必要です。
:::
