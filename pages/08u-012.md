## 記号を読む前に、小例へ戻る

intは整数、floatは小数を扱う型、strは文字列の型です。3、3.5、"3"は種類が違います。文字の"3"を数字に直すint("3")は3です。

`3`は整数のint、`0.5`は小数を扱うfloat、`"cat"`は文字列のstr、`True`と`False`は真偽値のboolです。文字列を囲む引用符は、そこがプログラムの命令ではなく文字のデータだと示します。

`type(x)`は、xが整数・文字列などのどの型かを調べる操作です。下の出力はPythonの型の名前を表示します。

```python
x = 3
print(type(x))
print(3 + 4)
print("3" + "4")
print(3 == 4)
```

結果は順に整数の型情報、7、文字列34、Falseです。数の3と文字の"3"は違います。`int("3")`で整数へ変換できますが、`int("cat")`は変換できずエラーになります。

Pythonの掛け算は`*`、割り算は`/`、べき乗は`**`です。`//`は床除算、`%`は剰余を表します。正の整数で7を3で割れば、`7//3`が2、`7%3`が1です。
