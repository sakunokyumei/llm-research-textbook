## 記号を読む前に、小例へ戻る

計算手順でくじのような列を作るのが疑似乱数。default_rngで生成器を作り、integers(0,3)で0,1,2の番号から選びます。3は含まれません。seedと版を記録して再開します。

```python
import numpy as np
rng = np.random.default_rng(42)
a = np.array([1, 1, 0, 1, 0, 1, 1, 0])
b = np.array([1, 0, 0, 1, 1, 1, 0, 0])
diff = a - b
idx = rng.integers(0, len(diff), size=(2000, len(diff)))
boot = diff[idx].mean(axis=1)
print("observed difference", diff.mean())
print("percentile interval", np.quantile(boot, [0.025, 0.975]))
```

これは手順を学ぶ8問の玩具例です。信頼できる性能主張に十分な標本とは限りません。固定した予測への問題の再抽出は、学習seedを変えて訓練をやり直す変動とは別です。独立した学習を複数回行うなら、両方の不確かさを区別して報告します。
