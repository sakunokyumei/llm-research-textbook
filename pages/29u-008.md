# 29-8 EmbeddingはIDを数の並びへ引く

この章の8/12ページ。今日の目標：EmbeddingはIDを数の並びへ引くの小例を一つ追う。

## 記号を読む前に、小例へ戻る

IDから数の行を引く表がEmbedding。ID用の整数の型がtorch.longです。表[[1,0],[0,2]]へID1を渡すと[0,2]。IDの大きさ1だから意味も1という計算ではありません。

語彙数V、特徴数dなら、[Embedding](reference.html#term-embedding)は(V,d)の学習可能な表です。トークンIDがiならi行目を取り出します。ID自体の数の大小に意味を与えるのではなく、取り出した[ベクトル](reference.html#term-vector)を学習します。ID100がID50の「二倍の意味」というわけではありません。

```python
import torch
from torch import nn
torch.manual_seed(42)
table = nn.Embedding(5, 3)
ids = torch.tensor([[0, 2, 4]], dtype=torch.long)
print(table(ids).shape)
```

出力は(1,3,3)で、バッチ1、トークン3、特徴3です。特殊トークンとして文書の終わりを示すEOSや長さ合わせのPADを設ける場合、それぞれの意味と[損失](reference.html#term-loss)から除外する位置を決めます。
