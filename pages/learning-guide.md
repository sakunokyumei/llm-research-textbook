# 学習ガイド：初めて来たら、ここから

このサイトは、算数とパソコンの基礎から、AIの仕組みを理解し、自分で実験して研究をまとめるところまで進む教科書です。LLMは「大規模言語モデル」の略で、文章の続きを予測する仕組みを土台にしたAIです。初日は、ソフトを入れたり論文を読んだりする必要はありません。

## どんな順番で進める？

初めて学ぶ場合は、第1章から番号順に進めます。後の章で必要になる考え方を、前の章で準備しています。全56章を一度に読み切る予定は立てず、読む・解く・実行する日を分けましょう。

| 順番 | 学ぶこと | できるようになること |
|---|---|---|
| [第1〜2章](01-start.html) | 学び方とPCの基本 | 予想と実際を分けて記録し、ファイルを保存する |
| [第3〜7章](03-arithmetic.html) | 算数、文字式、関数、対数 | 数式の記号を具体的な数や表に直す |
| [第8〜13章](08-python.html) | Pythonと実行の道具 | 自分で短いプログラムを書き、結果とエラーを確かめる |
| [第14〜23章](14-vectors.html) | モデルを支える数学 | 数の並び、変化、確率を使って計算する |
| [第24〜34章](24-learning.html) | 機械学習と言語モデル | 小さなモデルを作り、学習と生成を試す |
| [第35〜52章](35-data-scaling.html) | 調整、効率、評価、公開責任 | 比較実験を設計し、結果と限界を点検する |
| [第53〜56章](53-research-design.html) | 論文、実験計画、研究報告 | 自分の問いを実験で確かめ、他の人が試せる形でまとめる |

Pythonをすでに使える人も、第1章で学び方を確認した後、既知の章の確認問題や演習を試します。解答を見ずに解けて理由を説明できる部分は、必要に応じて復習して進めます。「言葉を聞いたことがある」だけで前提を飛ばす必要はありません。

## 一ページで何をする？

1. 「何ができるようになるか」を読み、今日試すことを一つ決めます。
2. 本文の例を追います。計算なら紙に一行ずつ、コードなら実行前に結果を予想します。
3. 確認問題や演習を、解答を閉じたまま試します。答えを開き、数値だけでなく理由も比べます。
4. 分からなければ、そのページの説明や[章ごとの補習](workshop-route.html)へ戻ります。補習には具体例、途中まで手伝う問題、自力で試す問題があります。
5. できたことと止まった場所をメモし、「次の小ページ」へ進みます。疲れたら、ここで終えて次の日に続けてかまいません。

読む目安と、問題を解く時間は別です。例えば30分ある日は「例を読む10分・一問を試す15分・記録する5分」のように区切れます。時間を超えたら途中で保存しましょう。分からない箇所があることを、自分の能力の判定に使いません。

## 「実装ラボ」「実験ラボ」って何？

このサイトでいう**実装ラボ**は、説明で学んだ仕組みを、プログラムとして作って動かす実習ページです。「実装」は、考え方を動くコードにすること。「ラボ」は実習の場所という意味です。特別な施設へ行く必要はありません。

例えば「文章を小さな単位に分ける」「小さな文章予測モデルを学習させる」「設定を一つ変え、結果を比べる」といった作業をします。実験は、ただ動かすだけでなく、予想・条件・実際の結果を記録して確かめることです。最初の訪問時に、ラボの一覧を理解する必要はありません。

**本格的なラボは、第8〜12章で保存・実行・エラーの読み方を学んでから使います。** 本文から案内された実習を、その都度一つ開いてください。小さな言語モデルを作る実習は、第29〜33章につながります。

| やりたいこと | 開く場所 | 必要なもの |
|---|---|---|
| 講義を読む、図を見る、手計算する | [第1章から順に読む](01-start.html) | スマホまたはPC、紙やメモ |
| 本文の例で分からなくなった | [全56章の補習と練習](workshop-route.html) | 本文と同じ。実行課題はPC |
| Pythonの実習を始める準備をする | [PCで実行する準備](pc-practice.html) | 自分の練習フォルダを使えるPC |
| 学んだ内容のプログラムを動かす | [実装ラボ](labs.html) | 準備済みのPCと、対応する章の知識 |
| 最後の研究を作業ごとに進める | [卒業研究の作業ガイド](capstone-sessions.html) | 第55章までの学習と、自分の実験記録 |

Pythonはこの教材で使うプログラミング言語です。サイトのコード欄は読むための表示で、Pythonをその場で実行する画面ではありません。CPUはPCの計算を担当する部品で、教材の基本ラボはPCのCPUで小さな実験を行います。外部AIサービスのAPIキー（サービスを使うための認証情報）は不要です。GPUを使う大規模な実験は発展内容です。

## スマホだけの日はどうする？

本文・図・確認問題を読み、手計算と出力の予想を残せます。Pythonを保存して実行する作業は、PCを使える日に回します。まだ実行していないものは「未実行」と記録すれば、次にすることが分かります。

各ページの再開メモは、その端末のブラウザ内に保存されます。別の端末へ自動で移るわけではありません。共有PCでは個人情報を書かず、使い終わったらメモを消してください。紙や自分のメモアプリを使ってもかまいません。

## メニューにあるページの使い分け

- **講義・全章目次**：初めて学ぶ本文です。章の番号順に進みます。
- **補習と練習**：本文で止まったとき、具体例を小さくして試す場所です。
- **まとめて参照**：章全体を一ページで見直す辞書のようなページです。最初から長いページを読み切る必要はありません。
- **用語・記号の早見表**：学んだ語の意味や式を忘れたときに引きます。
- **研究を読む**：論文と前提の章を結ぶ読書案内です。最初の日の必修課題ではありません。
- **卒業研究の手順**：実験、結果の保存、独自の変更、報告書を揃える最終段階の案内です。

## 何ができたら「修了」？

最後のページまで読んだことだけで修了とはしません。小さなモデルについて、自分の予想を立て、公平な条件で比べ、全結果を残し、失敗や限界を説明できることを目指します。第56章ではコード・テスト・実験記録・図表・報告書を揃えます。結果が予想に反していても、条件と確かめ方を説明できれば研究として報告できます。

今は最終課題を全部理解しなくても大丈夫です。まずは[第1章の最初の一ページ](01-start.html)で、「予想と実際を分けて書く」ところから始めましょう。
