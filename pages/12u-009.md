## 記号を読む前に、小例へ戻る

CPUは幅広い処理を行う装置、GPUは多数の似た計算に向く装置です。ドライバーはOSと装置の間の動作を助けるソフト。小さい実習はCPUで始め、GPU購入を前提にしません。

同じファイルでも、使う[ライブラリ](reference.html#term-library)が更新されると動作が変わることがあります。ライブラリは、他の人が用意した機能の集まりです。研究ではコードだけでなく、Python、ライブラリ、データ、実験設定の版も記録します。

CPUはプログラムの命令を実行する装置、GPUは同じ種類の計算を多数同時に行うのに向いた装置です。ドライバーはOSが装置を使うためのソフトウェアです。NumPyは数の並びや表を計算するためのライブラリで、以下ではその導入を例にします。

[仮想環境](reference.html#term-venv)は、プロジェクトごとにPythonの追加ライブラリを分ける仕組みです。以下はターミナルで実行します。`.venv`は作るフォルダの名前です。

```text
python -m venv .venv
```

Windowsでは`.venv\Scripts\python.exe`、macOS/Linuxでは`.venv/bin/python`が環境内のPythonです。以下の例はmacOS/Linuxの表記です。Windowsでは先頭を対応するパスへ置き換えます。環境を有効化する操作を省き、使うPythonを明示しています。

```text
.venv/bin/python -m pip install numpy
.venv/bin/python -m pip freeze > requirements.txt
```

pipはライブラリを管理する道具です。`>`は出力をファイルへ保存するターミナルの記法で、既存の同名ファイルを上書きします。実験ごとに別フォルダを作って保存してください。requirements.txtから復元するときは`python -m pip install -r requirements.txt`を使います。OSやGPUドライバーまではこのファイルだけで固定されません。
