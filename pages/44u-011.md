## 記号を読む前に、小例へ戻る

整数0へ実数0を合わせる対称量子化では、目盛り幅scaleで割って丸めます。0.26を幅0.1で3へ、戻すと0.3。zero pointは実数0に対応する整数の基準で、非対称方式では0以外になり得ます。

per-channelは出力の成分ごと、groupはまとめた一群ごとに目盛りの幅を分ける指定です。zero pointは整数0以外の値へ実数の0を対応させる場合の基準。今回は対称量子化で0をそのまま0へ対応させます。

```python
import numpy as np
W = np.array([[0.26, -0.34], [0.12, 0.49]])
x = np.array([2., 1.])
s = 0.1
q = np.clip(np.round(W / s), -7, 7)
restored = s * q
print(W @ x, restored @ x)
print(np.linalg.norm(W - restored))
```

roundは近い整数へ丸め、clipは範囲−7〜7へ制限します。NumPyのroundはちょうど中間の場合に偶数側へ丸める規約で、この入力には中間値がありません。元の出力は(0.18,0.73)、復元後は(0.3,0.7)。重み誤差が出力へどう響くかは入力にも依存します。[ノルム](reference.html#term-norm)は[第16章](16-tensors.html)へ、[行列](reference.html#term-matrix)積は[第15章](15-matrices.html)へ戻れます。
