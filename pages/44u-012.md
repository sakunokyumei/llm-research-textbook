# 44-12 演習

読む目安5〜10分／演習25〜50分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の12/13ページ。

このページの演習：「量子化」、「理想容量」、「校正」、「疎性」、「蒸留の評価」。

:::exercise 1・量子化
x=−0.34、s=0.1、範囲内として量子化・復元・絶対誤差を求めてください。
:::answer
q=−3、復元−0.3、絶対誤差0.04です。
:::

:::exercise 2・理想容量
100万個の重みをFP16から4bitへ変えると、重み本体の理想的な容量は何byteから何byteですか。
:::answer
200万byteから50万byteです。ただしscale、zero point、packing、その他のモデル状態は別です。
:::

:::exercise 3・校正
評価セットを使って最もよい量子化scaleを選ぶと何が問題ですか。
:::answer
評価データへ合わせ込んでしまいます。校正用データと最終評価を分離します。
:::

:::exercise 4・疎性
重みの90%が0になったので、必ず10倍速いと言えますか。
:::answer
言えません。ゼロを省く対応kernelや形式が必要で、転送・索引・不均一な処理の費用もあります。
:::

:::exercise 5・蒸留の評価
教師への一致率だけで、生徒の回答品質を十分に測れますか。
:::answer
不十分です。教師の誤答まで一致することがあるため、独立した正解や用途の基準でも評価します。
:::
