## 記号を読む前に、小例へ戻る

defで処理に名前を付けます。渡す値が引数、returnは計算結果を呼んだ側へ返す書き方です。2倍する処理へ3を渡せば6を返します。表示するprintとは役割が違います。

関数は、入力を受け取り、処理して結果を返す仕組みです。`def`で定義し、`return`で返します。括弧内の名前を引数と呼びます。

```python
def accuracy(correct, total):
    if total <= 0:
        raise ValueError("totalは正の数にしてください")
    return correct / total

result = accuracy(8, 10)
print(result)
```

結果は0.8です。`raise`は不適切な入力をエラーとして知らせます。`print`は表示、`return`は呼び出し元へ値を返す操作です。表示しただけでは、別の計算へ結果を渡せません。

[機械学習](reference.html#term-ml)の実験も、小さな関数を組み合わせます。データを読む、予測する、誤差を測る、保存する。役割を分けると、どこで間違ったかを調べやすくなります。
