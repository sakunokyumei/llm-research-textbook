# 19-7 足した値を残す一行

読む目安10〜20分／確認5〜10分。時間は編集上の目安です。

この章の7/11ページ。

買い物の合計へ次の品物の値段を足すのと同じです。`area += t * width`は、今回の小数の変数では `area = area + t * width` と同じ計算結果になります。`+=`を加算[代入](reference.html#term-substitution)と呼びます。後の回帰で使う `w -= change` は今回の数値なら `w = w - change` です。配列やリストでは、その物自体を書き換える場合があり、参照先への影響まで常に同じとは限りません。[Pythonの仕様](https://docs.python.org/3/reference/simple_stmts.html#augmented-assignment-statements)も確認できます。代入の復習は[第8章](08-python.html)、合計の繰り返しは[第9章](09-control.html)へ。

> 小例へ戻る：細かい区間の量を足し、その区切りを細かくした極限が積分。有限の区切りで近似するのが数値積分です。速度が時刻tなら0〜2を二分した中央の速度0.5,1.5に幅1を掛けて足し2になります。

n=2なら幅は1、中央の時刻は0.5と1.5です。

|区間|中央t|足す距離t×幅|合計area|
|---|---|---|---|
|0〜1|0.5|0.5|0.5|
|1〜2|1.5|1.5|2.0|

次のコードのnを2に変え、各回のareaを表示して表と比べてください。

```python
n = 1000
width = 2.0 / n
area = 0.0
for i in range(n):
    t = (i + 0.5) * width
    area += t * width
print(area)
```

各区間の中央の値を使っています。結果は丸め誤差の範囲で2です。この例の関数は直線なので中央の長方形による近似が特にうまくいきます。どんな曲線にも有限のnで正確という意味ではありません。
