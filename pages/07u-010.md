# 07-10 演習

読む目安5〜10分／演習30〜60分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の10/11ページ。

このページの演習：「逆向きに読む」、「対数の規則」、「誤った規則を反例で壊す」、「損失の方向」、「底を明示する」、「確率の積」。

:::exercise 1・逆向きに読む
log₂16、log₁₀1000、log₂1を求めてください。
:::answer
4、3、0です。それぞれ2⁴=16、10³=1000、2⁰=1へ書き戻して確かめます。
:::

:::exercise 2・対数の規則
log₂(8×16)を、掛け算を先にする方法と対数を足す方法で求めてください。
:::answer
8×16=128=2⁷なので7。またlog₂8+log₂16=3+4=7です。
:::

:::exercise 3・誤った規則を反例で壊す
log₂(x+y)=log₂x+log₂yは常に正しいですか。x=y=1で試してください。
:::answer
左辺はlog₂2=1、右辺は0+0=0。等しくありません。積の公式を和に使ってはいけません。
:::

:::exercise 4・損失の方向
正解の確率が0.25から0.5へ上がると、−ln pは増えますか、減りますか。
:::answer
減ります。約1.386から約0.693になります。正解へ高い確率を付けるほど、この[損失](reference.html#term-loss)は小さくなります。
:::

:::exercise 5・底を明示する
確率1/4の事象の−log₂pと−ln pを比べてください。
:::answer
前者は2 bit、後者はln4≈1.386 natです。単位・対数の底が違うので、数値をそのまま同じものとして比較できません。
:::

:::exercise 6・確率の積
二段階の条件付き確率がそれぞれ0.5と0.25なら、同時にその順序になる確率と負の対数を求めてください。
:::answer
確率は0.125。負の自然対数は−ln0.5−ln0.25≈0.693+1.386=2.079です。
:::
