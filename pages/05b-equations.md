# 05-2 天びんで方程式を解く

読む・手計算の目安：10〜15分。演習は10〜20分、コード実行は別の回へ分けられます。時間は編集上の目安です。

## 同じ量へ、同じ操作をする

<figure class="learning-figure"><svg viewBox="0 0 420 210" role="img" aria-labelledby="balance-title balance-desc"><title id="balance-title">左右へ同じ操作をする天びん</title><desc id="balance-desc">左の2xと3、右の11が釣り合う。両側から3を取り除くと2xと8が釣り合う。</desc><path d="M55 60 H365 M210 60 V130 M210 130 L180 155 H240 Z M70 60 V92 M350 60 V92 M35 92 H105 M315 92 H385" fill="none" stroke="#245da8" stroke-width="3"/><g fill="#17243b" font-size="22" text-anchor="middle"><text x="70" y="42">2x ＋ 3</text><text x="350" y="42">11</text><text x="210" y="184">両側から3を引く → 2x ＝ 8</text></g></svg><figcaption>同じ量を両側から取れば、釣り合いが保たれます。右からだけ取る操作ではありません。</figcaption></figure>

`2x+3=11`は左右の量が等しいという条件です。この条件を満たすxを探します。左の式と右の式を合わせて[両辺](reference.html#term-sides)と呼びます。両辺から3を引けば2x=8。両辺を2で割ればx=4です。左右に同じ操作をしたので等しさが保たれます。これが[方程式](reference.html#term-equation)を解くということです。

条件を満たした値x=4が[解](reference.html#term-solution)です。解を元の式へ戻して、2×4+3=11を確かめます。この答えの確認を[検算](reference.html#term-check-answer)と呼びます。途中の操作で間違えたり、0で割ったりしていないかを確認できるからです。今日は方程式・両辺・解・検算の四つを、天びんの同じ例で確認します。

:::exercise 3・方程式
3x−4=11を解き、元の式へ戻して確認してください。
:::answer
両辺に4を足して3x=15、3で割ってx=5。検算は3×5−4=11です。
:::
