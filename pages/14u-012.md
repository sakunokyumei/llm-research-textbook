このページの演習：「通常のforへ戻す」。

二つの並びを対応させる`zip(x,y)`は、この例では(3,4)、(4,3)という組を順に渡します。`a,b = (3,4)`はaへ3、bへ4を割り当てる書き方です。これを組の展開（アンパック）と呼びます。次のfor文は組を一つずつ受け取り、その場でaとbに分けます。

> 小例へ戻る：math.sqrt(9)は平方根3。zipは二つの並びから対応する組を取ります。組(100,2)をprice,countへ分けて受け取るのがアンパック。三件と二件のzipは短い方の二件で終わるので件数を確認します。

```python
x = [3, 4]
y = [4, 3]
products = []
for a, b in zip(x, y):
    products.append(a * b)
print(products)
print(sum(products))
```

出力は `[12, 12]` と24。`append`は末尾への追加、`sum`は合計です。この「組を取り出す→掛ける→追加する」を、`[a * b for a, b in zip(x, y)]`とも書けます。リストを作るこの書き方が内包表記です。

丸括弧の `(a * b for a, b in zip(x, y))` は、全結果のリストを先に作らず、求められた順に値を渡す生成式です。sumへ渡すと、それらを足します。次の二通りを比べてください。

```python
x = [3, 4]
y = [4, 3]
products = [a * b for a, b in zip(x, y)]
print(sum(products))
print(sum(a * b for a, b in zip(x, y)))
```

どちらも24です。sumの唯一の引数が生成式なら、その生成式用の括弧を一組省略できます。zipは標準では短い並びの終わりで止まるため、最初のコードの長さ確認は短縮版でも必要です。短い書き方を暗記するより、普通のfor文へ戻して説明できることを優先しましょう。

:::exercise 2・通常のforへ戻す
`sum(a * a for a in [1,2,3])`を、合計を0から始めるfor文で書き直してください。
:::answer
合計を0にし、1、2、3について順に `total = total + a * a` を実行します。合計は1、5、14と変わります。二乗してから足す順序が同じか確認してください。
:::
