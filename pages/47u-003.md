# 47-3 過去を全部持つ必要がある？

この章の3/7ページ。今日の目標：過去を全部持つ必要がある？の小例を一つ追う。

## 記号を読む前に、小例へ戻る

小さな状態を更新して列を処理する模型がSSM。前の状態から次を作るのが再帰的状態の更新、それを順に進める操作がscanです。状態0へ入力1,2,3を足す模型なら1,3,6。全部の過去をそのまま保存する方式ではありません。

会議の議事録を毎回すべて読み返す方法と、要点をメモに更新し続ける方法を比べます。[Attention](reference.html#term-attention)は過去の位置へ直接アクセスできます。一方、再帰的なモデルは状態という一定の大きさのメモを更新します。メモは安く持てますが、後で必要になる情報を捨ててしまうかもしれません。

状態空間モデル（SSM）の最も単純な離散形は `h_t = A h_(t−1) + B x_t, y_t = C h_t`。hは状態、xは入力、yは出力です。Aは過去をどう残すか、Bは新しい入力をどう加えるか、Cは状態から何を読むかを表します。hが二成分ならAは2×2[行列](reference.html#term-matrix)です。これはMambaそのものではなく、出発点となる仕組みです。
