# 52-8 モデルカードを書く

読む目安5〜10分／演習20〜40分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の8/9ページ。

このページの演習：「Git履歴」、「匿名化」、「保証の単位」、「公開前の実務」。

用途、想定外の用途、学習データの由来、版、言語別評価、既知の限界、ライセンス、計算条件をまとめます。open-weightは重みへのアクセスを意味し、無条件の利用・データ公開・完全な再現可能性を自動的に意味しません。

:::exercise 1・Git履歴
最新のファイルから秘密を消しました。公開してよいですか。
:::answer
履歴や他の成果物に残っていないか確認が必要です。有効な認証情報なら失効も必要です。公開対象の全体を調べます。
:::

:::exercise 2・匿名化
氏名を消し、学校・日付・珍しい経歴を残しました。匿名と断定できますか。
:::answer
できません。組合せで個人が特定される場合があります。用途に不要な詳細を減らします。
:::

:::exercise 3・保証の単位
一人が100件の文書を提供しています。文書単位の保証は一人単位と同じですか。
:::answer
同じではありません。隣接データの単位と複数文書をまとめた影響を確認します。
:::

:::exercise 4・公開前の実務
合成データ実験でも点検すべき情報を三つ挙げてください。
:::answer
ログ中のローカルパス、Gitの実名・メール、環境変数や認証情報、画像のメタデータなど。データ以外も対象です。
:::
