# 21-13 演習

読む目安5〜10分／演習25〜50分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の13/14ページ。

このページの演習：「期待値」、「分散」、「二項分布」、「単位」、「相関と因果」。

:::exercise 1・期待値
10点を確率0.2、0点を確率0.8で得るときの期待値を求めてください。
:::answer
10×0.2+0×0.8=2点です。必ず2点をもらえるという意味ではありません。
:::

:::exercise 2・分散
0と2が半々で出る変数の期待値・分散・標準偏差を求めてください。
:::answer
期待値1、分散(0−1)²×0.5+(2−1)²×0.5=1、標準偏差1です。
:::

:::exercise 3・二項分布
独立に正解する確率0.8の模型が10問に答えるとき、正解数の期待値と分散はいくつですか。
:::answer
期待値8、分散10×0.8×0.2=1.6。実際の問題の正誤が独立・同じ確率という仮定が妥当かは別途考えます。
:::

:::exercise 4・単位
時間を秒からミリ秒へ1000倍すると、分散と標準偏差はそれぞれ何倍ですか。
:::answer
分散は1000²=100万倍、標準偏差は1000倍です。
:::

:::exercise 5・相関と因果
長い回答ほど評価点が高いという相関がありました。回答を長くすれば必ず正しくなると言えますか。
:::answer
言えません。問題の難しさ、内容、採点者の長さへの好みなどが影響しているかもしれません。長さを変える介入と条件をそろえた比較が必要です。
:::
