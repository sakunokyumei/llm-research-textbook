# 37-7 演習

読む目安10〜20分／確認5〜10分。長いコードの実行はPCを使える別の回へ分けられます。時間は編集上の目安です。

この章の7/8ページ。今日の目標：演習の小例を一つ追う。

## 記号を読む前に、小例へ戻る

上位k件へ必要な根拠が入る割合をrecall@k等で測ります。oracle contextは実験用に正しい根拠を渡す対照です。10問中8問に根拠が入れば8/10。根拠を渡しても誤答するなら回答段階も調べます。

:::exercise 3・検索指標
必要文書が二つあり、上位5件に一つ入っていました。必要文書に対するrecall@5はいくつですか。
:::answer
1/2=0.5です。一件以上取れたというhit判定なら成功ですが、必要な根拠を全て取れたわけではありません。
:::

:::exercise 4・原因を調べる
oracle contextで正解、通常検索で不正解でした。次に何を読みますか。
:::answer
取得したchunk、順位、切れ目、文書版、質問表現を確認します。検索漏れや根拠の切断を調べます。
:::

:::exercise 5・引用
回答末尾に正しいWebページへのリンクがあれば、回答の全主張が根拠付きですか。
:::answer
いいえ。各主張がそのページのどの記述で支持されるかを確認する必要があります。
:::

:::exercise 6・chunkの長さ
chunkを大きくすれば常に検索がよくなりますか。
:::answer
常にではありません。根拠を保ちやすくなる一方、無関係な内容が混ざり、[トークン](reference.html#term-token)費用や検索表現へ影響します。長さを変えた比較を行います。
:::

:::exercise 7・資料の指示
取り込んだ文書にツール実行の命令がありました。研究用[エージェント](reference.html#term-agent)はどう扱うべきですか。
:::answer
文書内容は信頼境界の外にあるデータとして扱い、利用者の許可やシステム方針を上書きさせません。必要な操作は独立に検証します。
:::
