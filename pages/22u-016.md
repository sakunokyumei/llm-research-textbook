# 22-16 演習

## 記号を読む前に、小例へ戻る

差がない等の比較の基準が帰無仮説。データから計算する検定用の値が統計量です。その仮説と他の仮定のもとで観測以上に極端な値が出る確率がp値。公平なコインで二回とも表の確率1/4は確率計算の小例で、公平である確率1/4ではありません。

:::exercise 10・標準誤差
標本標準偏差が10、独立な観測が100個あるとき、平均の標準誤差の推定値はいくつですか。
:::answer
10/√100=1です。標準偏差10と標準誤差1は測っている揺れが違います。
:::

:::exercise 11・標本を増やす
同じ分布で件数を4倍にすると、平均の標準誤差はおおむねどうなりますか。
:::answer
1/√4=1/2になります。独立同分布などの条件が同じという前提です。
:::

:::exercise 12・p値の誤読
p=0.03を「仮説が誤りである確率97%」と言ってよいですか。
:::answer
いけません。p値は帰無仮説のもとでのデータの極端さに関する確率です。仮説そのものの事後確率ではありません。
:::

:::exercise 13・再抽出の単位
一つの長文から100個の文を切り出して評価しました。文を独立な100件として扱う場合の問題は何ですか。
:::answer
同じ文書由来の文には相関があり得ます。独立性を過大に見積もって区間を狭くする恐れがあります。文書単位の抽出など、データ生成過程に合う単位を考えます。
:::

:::exercise 14・学習と評価の揺れ
一つのモデルの固定予測を10000回bootstrapすれば、10種類の学習seedを試した代わりになりますか。
:::answer
なりません。bootstrapは固定予測に対する評価標本の変動です。学習時の初期値やデータ順序によるモデルの変動を測っていません。
:::

:::exercise 15・非有意の結論
有意差が出なかったとき、結果をどう書きますか。
:::answer
観測した差、区間、件数、検定方法を示し、この実験では差を十分に確定できなかったと述べます。同等性の主張には許容差を定めた別の設計が必要です。
:::
