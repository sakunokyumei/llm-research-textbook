# 19-10 追加の確認問題

読む目安10〜20分／確認5〜10分。長いコードの実行はPCを使える別の回へ分けられます。時間は編集上の目安です。

この章の10/11ページ。今日の目標：追加の確認問題の小例を一つ追う。

## 記号を読む前に、小例へ戻る

同じ幅の区間の起こりやすさが同じものが一様分布。幅へ掛けて確率にする高さが密度です。0〜2の一様分布は高さ1/2で全体の面積1。全体から取り出して調べる一部が標本です。

:::exercise 6・一定量の蓄積
速度3m/sで4秒進む距離を、積分の考え方で説明してください。
:::answer
幅4、高さ3の長方形に対応し、3×4=12mです。単位もm/s×s=mとなります。
:::

:::exercise 7・原始関数
∫₀³ 2t dtを求めてください。
:::answer
原始関数はt²なので3²−0²=9です。
:::

:::exercise 8・符号
−1から1までf(x)=xを積分すると何になりますか。
:::answer
負の三角形と正の三角形の寄与が打ち消し合い0です。図形の面積の合計なら1ですが、符号付き積分とは別です。
:::

:::exercise 9・密度と確率
0から0.5の一様分布の密度はいくつですか。1を超えてもよい理由を説明してください。
:::answer
密度は2です。幅0.5×高さ2=1なので全確率は1。密度は点の確率ではなく、範囲へ積分して確率にします。
:::
