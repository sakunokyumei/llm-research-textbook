# 43-8 演習

読む目安5〜10分／演習25〜50分。一問ずつ別の回に分けられます。時間は編集上の目安です。

この章の8/9ページ。

このページの演習：「時間を分ける」、「percentile」、「受理確率」、「速くならない条件」、「cacheと権限」。

:::exercise 1・時間を分ける
最初のトークンまで2秒、その後100トークンに1秒かかりました。TTFTと生成後半の速度を答えてください。
:::answer
TTFTは2秒、後半は100 token/sです。総時間で割った値と混ぜず、計測範囲を明記します。
:::

:::exercise 2・percentile
p99を平均遅延の99倍という意味に読んでよいですか。
:::answer
違います。観測分布の99パーセンタイルです。平均との倍率ではありません。
:::

:::exercise 3・受理確率
候補xにtargetが0.2、draftが0.4を付けたとき、上の受理確率はいくつですか。
:::answer
min(1,0.2/0.4)=0.5です。
:::

:::exercise 4・速くならない条件
draftモデルが大きく、提案のほとんどが棄却されます。何が起き得ますか。
:::answer
下書きの計算費用だけ増え、target単独より遅くなる可能性があります。受理率と総費用を測ります。
:::

:::exercise 5・cacheと権限
異なる利用者間でcacheを共有するとき、性能以外に何を確認しますか。
:::answer
権限のない情報や存在の手掛かりを漏らさないこと、model/prompt/configの一致、分離方針、削除や更新の扱いを確認します。
:::
