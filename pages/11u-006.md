## 記号を読む前に、小例へ戻る

sum([2,4])は合計6、abs(-3)は大きさ3です。計算機の小数には丸めがあるため、差の大きさが決めた許容誤差以下か確認します。差0.001で許容0.01なら範囲内です。

誤った平均を返すプログラムも、エラーを出さずに動くことがあります。そこで「この入力にはこの答えになるはず」という小さな約束を作り、実際の結果と比べます。これをテストと呼びます。

コードを読むための道具を三つ確認します。`len([2,4,6])`は要素の個数3、`sum([2,4,6])`は合計12、`abs(-3)`は符号を除いた大きさ3です。数学の絶対値の復習は[第3章](03-arithmetic.html)、繰り返して足す方法は[第9章](09-control.html)へ戻れます。下の平均は「合計÷個数」です。

```python
def mean(values):
    if len(values) == 0:
        raise ValueError("空の並びの平均は求めません")
    return sum(values) / len(values)

assert mean([2, 4, 6]) == 4
assert mean([7]) == 7
assert abs(mean([0.1, 0.2]) - 0.15) < 1e-12
print("checks passed")
```

assertは条件が偽なら止まって知らせます。最後の比較だけ誤差の許容幅を設けたのは、小数の計算が[有限精度](reference.html#term-finite)だからです。許容誤差を大きくしすぎると本当の間違いを見逃します。
