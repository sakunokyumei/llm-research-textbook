この教科書を最後までやり切る人と、途中でやめてしまう人の違いは、才能じゃない。「止まったときの作戦」を持っているかどうかだ。この付録は、その作戦をまとめた、いわば非常用の持ち出し袋だよ。

## 挫折の3大原因と、その作戦

| 原因 | よくある場面 | 作戦 |
|---|---|---|
| エラーで止まる | 赤い文字が出て、何をすればいいか分からない | **20分ルール**（下）。[エラー辞典](e-errors.html)。完成ノートで答え合わせ |
| 理論で止まる | 数式や新しい言葉が続いて、頭に入らない | **6割ルール**。コードを動かしてから戻る。[数学の地図](d-math.html)・[用語集](f-glossary.html) |
| 成果が見えなくて止まる | 何週間も進んでいる気がしない | **小さく記録**。「この章をクリアした！」ボタン、記録表、作ったものを人に見せる |

### 20分ルール

同じことで20分止まったら、次の順に助けを呼びます。

1. その章の「つまずき注意」の箱を読む
2. [付録E エラー辞典](e-errors.html)で、エラーの最後の行を検索
3. 生成AIに、下のテンプレートで質問する
4. それでもダメなら、**印をつけて先に進む**。後の章で分かることもよくあります

### 6割ルール

1回で全部分かる必要はありません。「なんとなく分かった」が6割くらいあれば、次の章へ進みましょう。この教科書では、大事な考え方（確率、損失、勾配、Attention）が、形を変えて何度も出てきます。2回目、3回目に会ったときに「あ、そういうことか！」と分かることがよくあります。

### 小さく記録

- 各章の終わりの **チェックリスト** と **「この章をクリアした！」ボタン**（目次にチェックが付きます。この端末のブラウザにだけ保存）
- 第5章から始まる **記録表**（モデルの検証損失）を、自分のノートにも書き写す
- 作ったもの（生成した文章、グラフ、公開したページ）を、友だちや家族に見せる。「すごいね」の一言は、最高の燃料です

## 学習計画の立て方

### ペースの目安

| ペース | 1週間の時間 | 完走までの期間 |
|---|---|---|
| ゆっくり | 週2〜3時間 | 約1年 |
| ふつう | 週4〜6時間 | 約半年 |
| 集中 | 週10時間以上（長期休み） | 2〜3か月 |

専門学校の授業や課題、アルバイトがある時期は「ゆっくり」で十分です。夏休みや春休みに「集中」で一気に進む、というメリハリもおすすめです。

### 1年生の1年間の例（ふつうのペース）

| 時期 | 進める章 | ひとこと |
|---|---|---|
| 1か月目 | 第0〜3章 | 最初の週末で第3章まで行ける。LLMを動かす楽しさを味わう |
| 2〜3か月目 | 第4〜7章 | 漱石で作る。対数・行列・微分。基本情報の勉強と相乗効果 |
| 4か月目 | 第8〜10章 | ニューラル言語モデル。第10章は2回に分けて |
| 5〜6か月目 | 第11〜13章 | Attention、Transformer、漱石GPT。ここが山場で、一番楽しいところ |
| 7〜8か月目 | 第14〜16章 | 本物に近づける。第15章の「一致した！」は感動もの |
| 9〜10か月目 | 第17〜20章 | 既製モデルを鍛えて、正しく測る |
| 11か月目 | 第21〜24章 | RAG、DPO、エージェント、公開 |
| 12か月目〜 | 第25〜26章 | 最新の部品、卒業制作 |

:::tip 試験の前は休んでいい
基本情報技術者試験や定期試験の前は、教科書を休んでかまいません。この教科書の「基本情報とつながる」の箱を読み返すと、試験勉強にもなります。休んだ後は、**最後に開いた章の「まとめ」を読み直してから**再開すると、スムーズに戻れます（トップページに「前回の続き」のリンクが出ます）。
:::

### 1回の学習の進め方（60分の例）

1. **5分**：前回の章の「まとめ」を読み返す
2. **10分**：今回の章の「この章でつくるもの」と、見出しを眺める
3. **40分**：コードを1セルずつ実行しながら読む。「やってみよう」は、予想を書いてから実行
4. **5分**：チェックリストを付けて、次にやることを1行メモ（「次は第8章の学習曲線から」）

区切りのいいところ（見出し1つ分）で止めてかまいません。

## AIに質問するテンプレート

生成AI（ChatGPT・Claude・Geminiなど。無料版でOK）は、24時間いつでも質問できる家庭教師です。うまく使うコツは、**状況を具体的に伝える**ことです。

### エラーを聞くとき

```text
『つくってわかるLLM』第◯章のコードを Google Colab（GPU：T4 ／ CPU）で実行したら、エラーが出ました。
初心者なので、原因と直し方を順番に教えてください。

【実行したコード】
（セルの中身をそのまま貼る）

【エラーメッセージ】
（赤い文字の、最後の10行くらいを貼る）

【試したこと】
（ランタイムを再起動した、など）
```

### 理論を聞くとき

```text
専門学校1年生で、Pythonを勉強し始めたばかりです。
『つくってわかるLLM』第◯章の「（分からない言葉や数式）」が分かりません。

【自分の理解】
（今、こう理解している、を書く。間違っていてもOK）

【分からないところ】
（どこから分からなくなったか）

高校数学の知識はあまりないので、具体的な数の例と、Pythonのコードで説明してください。
```

:::warn AIの答えも確かめる
AIの答えも、ときどき間違っています（第21章のハルシネーション）。教えてもらったコードは、必ず自分で実行して確かめましょう。それこそが、この教科書で身につけた「自分の手で確かめる」力の使いどころです。また、トークンやパスワードを貼らないように気をつけてください。
:::

## やる気がなくなったときの処方箋

| 症状 | 処方箋 |
|---|---|
| 何もやる気がしない | 5分だけ、トップページの漱石GPTで遊ぶ。または、第1章のボンゴ先生に何か聞く |
| 難しすぎて嫌になった | 1つ前の章の「やってみよう」に戻る。分かるところで成功体験をする |
| 進んでいる気がしない | 記録表を見る。第5章の 7.631 から、どこまで来たか |
| ほかの人と比べて焦る | 比べる相手は、1か月前の自分だけ。1か月前は、Attentionを書けなかったはず |
| 疲れている | 寝る。睡眠は脳のチェックポイント保存です（ボンゴ先生のデータより） |

:::sensei
最後に一つ。もし数週間、教科書を開かなかったとしても、それは失敗じゃない。いつ戻ってきてもいいように、各章は「その章の最初のセルから実行すれば必ず動く」ように作ってある。キミのペースで、また飛び込めばいい。プールはいつでも開いているよ。
:::
