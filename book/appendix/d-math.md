## よく出る式の読み方

### softmax（第3章）

$$p_i = \frac{e^{z_i}}{\sum_j e^{z_j}}$$

「$i$ 番目の点数の $e$ 乗を、全部の点数の $e$ 乗の合計で割る」。温度 $T$ をつけるときは、$z$ を $T$ で割ってから。

### 交差エントロピー（第5・8章）

$$L = -\frac{1}{N}\sum_{i=1}^{N} \log p(\text{正解}_i)$$

「各問題で、正解につけた確率の $\log$ を、マイナスにして平均する」。小さいほど良い。

### 勾配降下法（第7章）

$$w \leftarrow w - \eta \frac{\partial L}{\partial w}$$

$\eta$（イータ）は学習率。「傾きと逆向きに、学習率ぶん進む」。

### 連鎖律（第7章）

$$\frac{dy}{dx} = \frac{dy}{du}\cdot\frac{du}{dx}$$

「途中の傾きを、掛け算でつなぐ」。

### 全結合層（第9章）

$$\boldsymbol{y} = \boldsymbol{x}W + \boldsymbol{b}$$

### LayerNorm（第10章）

$$\mathrm{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta$$

$\mu$ は平均、$\sigma^2$ は分散、$\epsilon$ は0で割らないための小さな数、$\gamma$ と $\beta$ は学習する倍率と足し算。

### Attention（第11章）

$$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d}}\right)V$$

$K^\top$ は $K$ の**転置**（行と列の入れ替え）。

### 学習の計算量（第15章）

$$C \approx 6ND$$

$N$ はパラメータ数、$D$ は学習するトークン数。

### LoRA（第19章）

$$W' = W + \frac{\alpha}{r}BA$$

### KLダイバージェンス（第22章）

$$\mathrm{KL}(p \,\|\, q) = \sum_i p_i \log \frac{p_i}{q_i}$$

「$p$ の確率で重みをつけて、$\log$（$p$ ÷ $q$）を足す」。2つの分布が同じなら0、違うほど大きい。

### DPO（第22章）

$$L = -\log \sigma\big(\beta[(\log\pi(y_c) - \log\pi_{\text{ref}}(y_c)) - (\log\pi(y_r) - \log\pi_{\text{ref}}(y_r))]\big)$$

## ギリシャ文字の読み方

| 文字 | 読み | この教科書での主な使い道 |
|---|---|---|
| $\alpha$ | アルファ | LoRAの効き具合 |
| $\beta$ | ベータ | DPOの離れにくさ |
| $\gamma$ | ガンマ | LayerNormの倍率 |
| $\epsilon$ | イプシロン | 0で割らないための小さな数 |
| $\eta$ | イータ | 学習率 |
| $\theta$ | シータ | 角度、パラメータ全体 |
| $\mu$ | ミュー | 平均 |
| $\pi$ | パイ | 方策（第22章のLLM）。円周率ではない！ |
| $\sigma$ | シグマ（小文字） | 標準偏差、シグモイド関数 |
| $\Sigma$ / $\sum$ | シグマ（大文字） | 全部足す |
| $\nabla$ | ナブラ | 勾配 |
| $\partial$ | デル、ラウンドディー | 偏微分 |
