## 文章をまとめて計算する形

一つの単語をd個の数で表し、T個の単語を並べると(T,d)の行列です。さらにB本の文章をまとめると(B,T,d)の三次元配列になります。この教材でテンソルというときは、主にこの多次元配列の意味で使います。数学のより一般的なテンソル概念とは文脈が違います。

shapeは各軸の長さです。(2,3,4)なら2×3×4=24個の値があります。最初の軸が何を意味するかは、プログラマが決めた約束です。shapeだけを見て「必ずバッチ軸」と断定せず、名前も書きます。

NumPyのbroadcastは、末尾の軸から比べて長さが一致するか、どちらかが1なら、演算時に形をそろえる仕組みです。(2,3)へ(3,)を足すと各行に同じ三つの値を足せます。便利ですが、意図しない形でも通ることがあります。

```python
import numpy as np
x = np.arange(6).reshape(2, 3)
bias = np.array([10, 20, 30])
print(x + bias)
print(x.mean(axis=0))
print(x.mean(axis=1))
```

axis=0は行方向をまとめて各列の平均[1.5,2.5,3.5]、axis=1は各行の平均[1,4]です。reshapeは要素数を変えずに形を変えます。transposeは軸を入れ替えるので、同じ操作ではありません。

## 変換しても向きが変わらない

A=[[2,0],[0,1]]は横方向を2倍、縦方向をそのままにします。(1,0)は(2,0)へ変わり、向きは同じ。`Av=λv`を満たす0でないvを固有ベクトル、倍率λを固有値と呼びます。この例の横方向の固有値は2、縦方向は1です。

どんな実行列にも実数の固有ベクトルが十分にそろうとは限りません。一方、特異値分解SVDは実数のm×n行列を`A=UΣVᵀ`と表します。V側の方向へ入力を分け、非負の特異値で伸縮し、U側の方向へ組み直すと考えられます。

## 重要な方向だけ残す

対角行列diag(3,1)は二方向に情報を持ちます。大きな特異値3の方向だけ残してdiag(3,0)とするとランク1の近似です。失われた成分の大きさはFrobeniusノルムで1。一般に上位r個の特異値を残すSVD近似は、このノルムに関する最良のランクr以下の近似になります。

これは「小さい特異値はあらゆるタスクで不要」という意味ではありません。行列の再構成誤差を小さくすることと、モデルの予測品質を守ることは別です。LoRAでは重みそのもののSVD圧縮と異なり、更新分を低ランクの積として学びます。

## 演習

:::exercise 1・要素数
shapeが(4,8,16)の配列には何個の値がありますか。
:::answer
4×8×16=512個。1個4バイトなら配列本体は2048バイトです。
:::

:::exercise 2・broadcast
(2,3)と(2,)はそのまま要素ごとに足せますか。
:::answer
末尾の3と2が一致せず、どちらも1でないため足せません。各行に一つずつ足す意図なら(2,1)に形を整えます。
:::

:::exercise 3・軸
文章ごとの値が(バッチ数,単語数)の形にあるとき、各文章の平均を出すにはどの軸をまとめますか。
:::answer
単語数の軸、つまりaxis=1です。axis=0だと別の文章の同じ位置を混ぜてしまいます。
:::

:::exercise 4・固有値
A=diag(5,2)とv=(0,1)についてAvと固有値を答えてください。
:::answer
Av=(0,2)=2vなので固有値は2です。
:::

:::exercise 5・低ランク近似
diag(4,2,1)を上位一つの特異値だけで近似したとき、Frobeniusノルムでの誤差は何ですか。
:::answer
残る近似はdiag(4,0,0)、差はdiag(0,2,1)。全要素の二乗和の平方根なので√5です。
:::

## 到達課題と出典

NumPyの`np.linalg.svd`で小行列を分解し、`(U * s) @ Vh`が元に戻るか確認してください。`full_matrices=False`を使うと形を合わせやすくなります。[NumPy broadcasting](https://numpy.org/doc/stable/user/basics.broadcasting.html)、[SVD](https://numpy.org/doc/stable/reference/generated/numpy.linalg.svd.html) が参照先です。
