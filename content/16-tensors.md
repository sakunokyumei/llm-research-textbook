## 文章をまとめて計算する形

一つの単語をd個の数で表し、T個の単語を並べると(T,d)の行列です。さらにB本の文章をまとめると(B,T,d)の三次元配列になります。この教材でテンソルというときは、主にこの多次元配列の意味で使います。数学のより一般的なテンソル概念とは文脈が違います。

複数の文章などをひとまとめに処理する、その一組をバッチと呼びます。shapeは各軸の長さです。(2,3,4)なら2×3×4=24個の値があります。最初の軸が何を意味するかは、プログラマが決めた約束です。shapeだけを見て「必ずバッチ軸」と断定せず、名前も書きます。

NumPyのbroadcastは、末尾の軸から比べて長さが一致するか、どちらかが1なら、演算時に形をそろえる仕組みです。(2,3)へ(3,)を足すと各行に同じ三つの値を足せます。便利ですが、意図しない形でも通ることがあります。

`np.arange(6)`は0、1、2、3、4、5を並べた配列を作ります。末尾の6は含みません。`reshape(2,3)`は要素の順序を保って2行3列へ置き直します。`mean`は平均、`axis`はどの軸をまとめるかの指定です。

```python
import numpy as np
x = np.arange(6).reshape(2, 3)
bias = np.array([10, 20, 30])
print(x + bias)
print(x.mean(axis=0))
print(x.mean(axis=1))
```

axis=0は行方向をまとめて各列の平均[1.5,2.5,3.5]、axis=1は各行の平均[1,4]です。reshapeは要素数を変えずに形を変えます。transposeは軸を入れ替えるので、同じ操作ではありません。

ここで一度休憩できます。2行3列の表を紙に描き、各行と各列の平均を自分で求めてから次へ進みます。

## まず、対角行列を紙に書く

行列の左上から右下に並ぶ成分を対角成分と呼びます。対角成分以外がすべて0の正方形の行列が対角行列です。diag(3,1)という略記は、次の表を表します。

| |1列目|2列目|
|---|---|---|
|1行目|3|0|
|2行目|0|1|

列ベクトル(2,5)へ掛けると、第一成分は3×2+0×5=6、第二成分は0×2+1×5=5。つまり横を3倍、縦を1倍にします。diag(4,2,1)なら3行3列で、対角線に4、2、1、残りの六つの位置には0を置きます。行列積を追えないときは[第15章](15-matrices.html)の内積の計算へ戻れます。

:::exercise 1・対角行列を展開する
diag(5,2)を全四要素で書き、(0,1)に掛けてください。
:::answer
[[5,0],[0,2]]です。結果は(5×0+0×1, 0×0+2×1)=(0,2)。略記を普通の行列に直せば、既習の掛け算です。
:::

## 同じ直線上へ移る方向

A=[[2,0],[0,1]]は横方向を2倍、縦方向をそのままにします。(1,0)は(2,0)へ変わり、向きは同じ。`Av=λv`を満たす0でないvを固有ベクトル、倍率λを固有値と呼びます。この例の横方向の固有値は2、縦方向は1です。固有値が負なら向きは反転し、0ならゼロベクトルに移ります。「いつでも向きが同じ」という意味ではありません。

どんな実数の行列にも、実数の固有ベクトルが十分にそろうとは限りません。そこで、行列を別の方法で分解する考えへ進みます。ここまでの固有値の演習だけを終え、次の小節は別の日にしてもかまいません。

## SVDを三つの行列で確かめる

入力の方向をそろえ、各方向を伸ばし、出力の方向へ組み直すと、複雑な変換も説明しやすくなります。この分け方が特異値分解で、SVDと略します。方向ごとの伸ばす倍率が特異値で、0以上の数です。

まずA=diag(3,1)にします。この場合、方向の変更は不要なので、UとVᵀの両方を[[1,0],[0,1]]、Σをdiag(3,1)にできます。[[1,0],[0,1]]は何を掛けても元のままにする単位行列です。Σはここでは行列の名前であり、[第6章](06-functions.html)の足し算の記号ではありません。

式で書くとA=UΣVᵀです。右側から作用するので、入力(2,5)はVᵀで(2,5)、Σで(6,5)、Uで(6,5)になります。三段階を合わせると、元のAを直接掛けた結果と同じです。

次はA=[[0,1],[3,0]]。Vᵀを[[0,1],[1,0]]へ変えると、入力(2,5)は(5,2)へ入れ替わります。それをΣ=diag(3,1)で(15,2)へ伸ばし、Uを単位行列にすればそのままです。元のAを掛けても(15,2)。対角行列以外でも三段階が対応しました。

一般の行列でも、V側とU側は互いに直角で長さ1の方向を選びます。これは[第14章の内積と長さ](14-vectors.html)で確認できます。方向を選ぶための数値計算は、ここではNumPyに任せ、戻る値の意味と再構成を確かめます。

## 戻る値の形を決めてから実行する

行列Aがm行n列なら、kをmとnの小さい方とします。必要な方向の本数だけを返す指定が `full_matrices=False` です。これは小さい特異値を捨てる指定ではありません。

|戻る値|形|役割|
|---|---|---|
|U|(m,k)|出力側の方向を列に持つ|
|s|(k,)|大きい順に並んだ特異値の一覧|
|Vh|(k,n)|入力側の方向を行に持つ|

この章では実数を使うため、Vhは式のVᵀに対応します。sは一覧で、Σはその値を対角線へ並べた行列です。`np.diag(s)`で一覧から対角行列を作れます。たとえば2行3列ならk=2で、Uは(2,2)、sは(2,)、Vhは(2,3)。積の形は(2,2)×(2,2)×(2,3)=(2,3)に戻ります。

```python
import numpy as np
A = np.array([[0., 1., 0.], [3., 0., 0.]])
U, s, Vh = np.linalg.svd(A, full_matrices=False)
Sigma = np.diag(s)
rebuilt = U @ Sigma @ Vh
print(U.shape, s.shape, Vh.shape)
print(s)
print(rebuilt)
print(np.allclose(A, rebuilt))
assert np.allclose(A, rebuilt)
```

三つの戻り値を三つの名前へ分ける代入は[第14章のアンパック](14-vectors.html)と同じ考えです。`shape`で形を取り出し、`@`で行列積を計算します。`np.allclose`は丸めによる小さな差を許して、各要素がおよそ一致するかを調べます。

形の出力は `(2, 2) (2,) (2, 3)`、特異値は `[3. 1.]`、最後は `True`です。途中の方向の符号が違っても、積が同じになる分解があります。Uの数値そのものを暗記して照合せず、再構成と形を確かめましょう。

`(U * s) @ Vh`も同じ再構成です。sの各値がUの対応する列全体へ掛かるためです。まず `U @ np.diag(s) @ Vh`で意味を確認してから短い形へ進みます。

## 大きな方向だけ残すと何が失われるか

diag(3,1)の二つ目の特異値を0にするとdiag(3,0)。独立な方向が一つだけ残るので、[第15章のランク](15-matrices.html)は1です。これが低ランク近似の例です。

元との差はdiag(0,1)。行列の全要素を二乗して足し、その平方根を取る大きさをFrobenius（フロベニウス）ノルムと呼びます。この例の誤差は√(0²+0²+0²+1²)=1です。[平方根の復習](04d-roots.html)へ戻れます。

```python
import numpy as np
A = np.array([[0., 1., 0.], [3., 0., 0.]])
U, s, Vh = np.linalg.svd(A, full_matrices=False)
kept = s.copy()
kept[1] = 0
approx = U @ np.diag(kept) @ Vh
error = np.linalg.norm(A - approx, ord="fro")
print(approx)
print(error)
assert np.allclose(error, 1.0)
```

`copy`で元の一覧を保ち、位置1にある二つ目の特異値だけを0にします。`ord="fro"`は先ほどの全要素の二乗和の平方根を使う指定です。近似は[[0,0,0],[3,0,0]]、誤差は1になります。

一般にも、大きい方からr個の特異値を残す方法は、この誤差についてランクr以下の最良の近似の一つになります。ただし行列の差が小さいことと、文章の予測結果がよいことは別です。近似した後の課題の成績も測る必要があります。

## 演習

:::exercise 2・要素数
shapeが(4,8,16)の配列には何個の値がありますか。
:::answer
4×8×16=512個。1個4バイトなら配列本体は2048バイトです。
:::

:::exercise 3・broadcast
(2,3)と(2,)はそのまま要素ごとに足せますか。
:::answer
末尾の3と2が一致せず、どちらも1でないため足せません。各行に一つずつ足す意図なら(2,1)に形を整えます。
:::

:::exercise 4・軸
文章ごとの値が(バッチ数,単語数)の形にあるとき、各文章の平均を出すにはどの軸をまとめますか。
:::answer
単語数の軸、つまりaxis=1です。axis=0だと別の文章の同じ位置を混ぜてしまいます。
:::

:::exercise 5・固有値
A=diag(5,2)とv=(0,1)についてAvと固有値を答えてください。
:::answer
Av=(0,2)=2vなので固有値は2です。
:::

:::exercise 6・低ランク近似
diag(4,2,1)を上位一つの特異値だけで近似したとき、Frobeniusノルムでの誤差は何ですか。
:::answer
残る近似はdiag(4,0,0)、差はdiag(0,2,1)。全要素の二乗和の平方根なので√5です。
:::
