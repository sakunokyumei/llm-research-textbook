## 同じ計算を何度も頼む

1000件の正解率を毎日計算するなら、電卓へ同じ手順を入力するのは大変です。コンピュータへ「この順に計算して」と渡す文章がプログラムです。ここではPythonという言語で書きます。初めは高度な開発環境は不要です。

Python公式のインストーラーを使い、手元でターミナルを開きます。WindowsではPowerShell、macOSやLinuxではターミナルを使えます。下の一行を入力してEnterを押します。Windowsで`python`が見つからず`py`が使える場合は、以降の`python`を`py`へ読み替えます。

```text
python --version
```

これはPythonのコードではなく、OSへ実行を頼むコマンドです。バージョンが表示されれば準備ができています。後の実験では使用したバージョンも記録します。インストールは [Python公式](https://www.python.org/downloads/) の案内を使ってください。

## ファイルを実行する

テキストエディターで、次の三行を`first.py`という名前で保存してください。Windowsでは拡張子が隠れていると`first.py.txt`になりやすいので、ファイル名を確認します。ターミナルの作業場所をそのフォルダに合わせ、`python first.py`と入力します。

```python
correct = 80
total = 100
print(correct / total)
```

出力は`0.8`です。`print(...)`は括弧内の結果を画面へ出す関数です。`=`は、右側の値へ左側の名前を付ける代入です。数学の「左右が等しいという条件」とは異なります。等しいかを調べるPythonの記号は`==`です。

`correct = 90`に変えて再実行すると0.9になります。変数とは、値を参照するために付ける名前です。同じ名前へ別の値を割り当てることもできます。

## 値には種類がある

`3`は整数のint、`0.5`は小数を扱うfloat、`"cat"`は文字列のstr、`True`と`False`は真偽値のboolです。文字列を囲む引用符は、そこがプログラムの命令ではなく文字のデータだと示します。

```python
x = 3
print(type(x))
print(3 + 4)
print("3" + "4")
print(3 == 4)
```

結果は順に整数の型情報、7、文字列34、Falseです。数の3と文字の"3"は違います。`int("3")`で整数へ変換できますが、`int("cat")`は変換できずエラーになります。

Pythonの掛け算は`*`、割り算は`/`、べき乗は`**`です。`//`は床除算、`%`は剰余を表します。正の整数で7を3で割れば、`7//3`が2、`7%3`が1です。

## エラーは観測結果

`pritn(3)`と打つとNameErrorになります。知らない名前が使われたという意味です。英語のエラー表示を全部理解する必要はありません。まず最後の行にあるエラーの種類と、直前のファイル名・行番号を確認します。予想した結果と実際の結果を分けて記録し、一箇所ずつ直します。

## 演習

:::exercise 1・実行前に予想する
`print(2 + 3 * 4)`と`print((2 + 3) * 4)`の出力を予想し、動かしてください。
:::answer
14と20です。算数で学んだ優先順位と一致します。実行できたことだけでなく、予想と一致したかも記録します。
:::

:::exercise 2・代入の意味
`x=3`、次に`x=x+2`、最後に`print(x)`を実行するとどうなりますか。
:::answer
5です。二行目は古いxの値3へ2を足し、その結果5へxという名前を付け直します。数学の方程式x=x+2を解いているのではありません。
:::

:::exercise 3・型の区別
`"12" + "3"`と`int("12") + 3`の結果はどう違いますか。
:::answer
前者は文字列"123"、後者は整数15です。ファイルから読み込んだ数値は文字列であることがあるので、型の確認が必要です。
:::

:::exercise 4・研究の計算を実装する
正解58件、全体100件の正解率を計算して表示する三行のプログラムを書いてください。
:::answer
`correct = 58`、`total = 100`、`print(correct / total)`です。結果は0.58。百分率で表示するならさらに100を掛けます。
:::

:::exercise 5・エラーを直す
`print(score)`だけのファイルでNameErrorが出ました。原因と、最小の修正を書いてください。
:::answer
scoreという名前にまだ値を割り当てていません。前に`score = 0.8`を追加すれば表示できます。実際のプログラムでは値をどこで作るべきかを考えます。
:::

## 到達課題と出典

算数の章の全体正解率を計算するプログラムを作り、数字を変えて再実行してください。言語仕様は [Python公式チュートリアル](https://docs.python.org/3/tutorial/) に対応します。同チュートリアル自体はプログラミング経験者向けなので、本章では実行と型から説明しました。
