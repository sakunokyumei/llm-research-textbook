## 平均が同じでも、体験は違う

毎日必ず500円もらう場合と、半分の日に0円、残りに1000円もらう場合を考えます。長期的な平均はどちらも500円ですが、不確かさは違います。確率で決まる数を確率変数Xと呼びます。取り得る値とその確率の組が分布です。

離散的な確率変数の[期待値](reference.html#term-expectation)は`E[X]=Σₓ x P(X=x)`。0と1000が半々なら0×0.5+1000×0.5=500。期待値が実際に出る値とは限りません。公平なサイコロの期待値3.5は、出目に存在しません。

## 散らばりをどう測るか

平均との差をそのまま足すと正負が打ち消されます。そこで二乗した差の平均を取ります。[分散](reference.html#term-variance)は`Var(X)=E[(X−μ)²]`、μは期待値です。0と1000が半々なら分散は250000円²。平方根を取った標準偏差は500円で、元の単位に戻ります。

有限データ全体の散らばりを記述するなら二乗偏差をnで割ります。独立同分布の標本から母分散の不偏推定をするなら、標本平均からの二乗偏差をn−1で割る標本分散を使います。何を求めるかによって分母が違います。

## nとn−1は何の違いか

独立同分布とは、一つを知っても他の起こりやすさが変わらず、同じ分布から得たという仮定です。母分散は調べたい全体の分散、不偏推定とは同じ標本抽出を繰り返したとき推定値の平均が真の値に一致する性質です。一回の推定が必ず真の値になる意味ではありません。

標本平均を同じ標本から求めると、平均との差は合計0になり、自由に動ける差が一つ減ります。独立同分布・有限分散の条件では、二乗差の和の期待値が `(n−1)×母分散` となるため、不偏に推定する分母はn−1です。n=1ではこの標本分散を計算できません。まずデータ `[1,2,3]` で平均2、二乗差の合計2を出し、全体の記述なら2/3、母分散を推定するこの方法なら2/2=1と区別します。

## よく使う分布

成功を1、失敗を0とする一回の試行はBernoulli分布で表せます。成功確率pなら期待値p、分散p(1−p)。独立なn回の成功数は[二項分布](reference.html#term-binomial)で、期待値np、分散np(1−p)です。

複数の候補から一つを選ぶ場合はカテゴリ分布。LLMの次[トークン](reference.html#term-token)確率も語彙に対するカテゴリ分布です。連続値の正規分布は平均を中心に左右対称な釣り鐘型の[密度](reference.html#term-density)を持ち、平均μと分散σ²で指定されます。すべてのデータが正規分布に従うわけではありません。

## 一緒に動くかを測る

共分散は`E[(X−E[X])(Y−E[Y])]`。二つが一緒に増えやすいなら正、逆なら負になりやすいです。標準偏差で割った相関[係数](reference.html#term-coefficient)は単位の影響を除きます。相関は因果関係を証明しません。共通する第三の要因が両方を動かす場合もあります。また相関0でも非線形の依存関係はあり得ます。

```python
import numpy as np
x = np.array([1., 2., 3.])
print(x.mean())
print(x.var(ddof=0))
print(x.var(ddof=1))
```

平均2、記述的な分散2/3、n−1で割った分散1になります。NumPyではddofという引数で分母n−ddofを指定します。

## 演習

:::exercise 1・期待値
10点を確率0.2、0点を確率0.8で得るときの期待値を求めてください。
:::answer
10×0.2+0×0.8=2点です。必ず2点をもらえるという意味ではありません。
:::

:::exercise 2・分散
0と2が半々で出る変数の期待値・分散・標準偏差を求めてください。
:::answer
期待値1、分散(0−1)²×0.5+(2−1)²×0.5=1、標準偏差1です。
:::

:::exercise 3・二項分布
独立に正解する確率0.8の模型が10問に答えるとき、正解数の期待値と分散はいくつですか。
:::answer
期待値8、分散10×0.8×0.2=1.6。実際の問題の正誤が独立・同じ確率という仮定が妥当かは別途考えます。
:::

:::exercise 4・単位
時間を秒からミリ秒へ1000倍すると、分散と標準偏差はそれぞれ何倍ですか。
:::answer
分散は1000²=100万倍、標準偏差は1000倍です。
:::

:::exercise 5・相関と因果
長い回答ほど評価点が高いという相関がありました。回答を長くすれば必ず正しくなると言えますか。
:::answer
言えません。問題の難しさ、内容、採点者の長さへの好みなどが影響しているかもしれません。長さを変える介入と条件をそろえた比較が必要です。
:::
