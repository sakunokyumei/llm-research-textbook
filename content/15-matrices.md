## 二つの出力を一度に作る

入力x=(2,3)から、出力の一つ目を2x₁+x₂、二つ目を−x₁+3x₂にしたいとします。それぞれ内積です。係数を二行に並べたA=[[2,1],[-1,3]]を使うと、二つの計算を`y=Ax`とまとめられます。結果は(7,7)です。

行列は数を行と列に並べたものです。Aは2行2列。形を(2,2)と書きます。一般にAがm行n列、xがn個の列ベクトルなら、Axはm個の列ベクトルです。内側のnが一致している必要があります。

## 行列積を一つずつ計算する

A=[[1,2],[3,4]]、B=[[5,6],[7,8]]とします。ABの左上は、Aの最初の行とBの最初の列の内積なので1×5+2×7=19。同様に右上22、左下43、右下50です。各要素を単に掛ける計算とは違います。

`(AB)ᵢⱼ=Σₖ Aᵢₖ Bₖⱼ`と書けます。iは出力の行、jは出力の列、kは足し合わせる方向です。Aが(m,n)、Bが(n,p)ならABは(m,p)。一般にはABとBAは同じにならず、片方しか計算できない場合もあります。

転置Aᵀは行と列を交換します。形(m,n)は(n,m)へ変わります。AttentionのQKᵀは、各queryと各keyを内積で比べるためにこの転置を使います。

## 基底・次元・連立方程式

二次元のベクトルは(1,0)と(0,1)を使ってx₁(1,0)+x₂(0,1)と表せます。重複のない基本方向の組が基底で、その本数が次元です。二つの列が同じ向きなら独立の情報は一方向分しかありません。独立な列の数をランクと呼びます。

`x+y=5`、`x−y=1`を足すと2x=6なのでx=3、y=2です。これもAx=bという行列の形にできます。逆行列は変換を元に戻す行列ですが、すべての行列に存在するわけではありません。二行が同じなら、二つの独立な条件がありません。数値計算では逆行列を明示的に作るより、連立方程式を解く専用関数を使います。

```python
import numpy as np
A = np.array([[1., 1.], [1., -1.]])
b = np.array([5., 1.])
x = np.linalg.solve(A, b)
print(x)
print(A @ x)
```

NumPyは数の配列を扱うライブラリです。未導入なら前章の仮想環境へnumpyをインストールします。`@`は行列積で、`*`は要素ごとの積です。出力は[3,2]と[5,1]になります。

## 演習

:::exercise 1・行列とベクトル
[[2,0],[1,3]]に列ベクトル(4,2)を掛けてください。
:::answer
第一成分2×4+0×2=8、第二成分1×4+3×2=10なので(8,10)です。
:::

:::exercise 2・形
(3,4)の行列と(4,7)の行列の積の形は何ですか。逆順も可能ですか。
:::answer
(3,7)です。逆順は内側が7と3で一致しないため計算できません。
:::

:::exercise 3・交換できない例
A=[[1,1],[0,1]]、B=[[2,0],[0,3]]のABとBAを求めてください。
:::answer
AB=[[2,3],[0,3]]、BA=[[2,2],[0,3]]です。右上が違い、変換の順序に意味があると分かります。
:::

:::exercise 4・独立な方向
(1,2)と(2,4)は二次元全体の基底になりますか。
:::answer
なりません。後者は前者の2倍で同じ直線上にあり、二つを組み合わせてもその直線以外へ進めません。
:::

:::exercise 5・方程式
2x+y=7、x−y=2を解いてください。
:::answer
二式を足して3x=9、x=3。x−y=2からy=1。元の両式へ代入して確認できます。
:::
