## 人が毎回判断しなくてよいように

点数が合格基準以上か、100件の答えが正しいか。コンピュータに任せたい作業には、判断と繰り返しが含まれます。`if`は条件で処理を分け、`for`は複数の値に対して処理を繰り返します。

```python
score = 75
if score >= 60:
    print("合格")
else:
    print("もう一度練習")

for value in [2, 4, 6]:
    print(value * 2)
```

出力は「合格」、4、8、12です。`>=`は以上、`[]`で囲んだ値の並びはリストです。コロンの次に続く行は空白4個分だけ下げます。この字下げ、つまりインデントが同じ処理のまとまりを示します。見た目だけの飾りではありません。

## 足し合わせる処理を追う

```python
total = 0
for value in [2, 4, 6]:
    total = total + value
print(total)
```

最初にtotalは0。1回目に2、2回目に6、3回目に12になります。最後のprintは字下げされていないので、ループが終わった後に一度だけ実行されます。

`range(3)`は0,1,2という三つの整数を順に使うための仕組みです。3を含みません。`while`は条件が真の間繰り返します。終了条件を変え忘れると終わらなくなるので、回数が決まる場合はforから始めましょう。

## 処理へ名前を付ける

関数は、入力を受け取り、処理して結果を返す仕組みです。`def`で定義し、`return`で返します。括弧内の名前を引数と呼びます。

```python
def accuracy(correct, total):
    if total <= 0:
        raise ValueError("totalは正の数にしてください")
    return correct / total

result = accuracy(8, 10)
print(result)
```

結果は0.8です。`raise`は不適切な入力をエラーとして知らせます。`print`は表示、`return`は呼び出し元へ値を返す操作です。表示しただけでは、別の計算へ結果を渡せません。

機械学習の実験も、小さな関数を組み合わせます。データを読む、予測する、誤差を測る、保存する。役割を分けると、どこで間違ったかを調べやすくなります。

## 演習

:::exercise 1・境界を試す
上の合格判定でscore=60と59の場合を予想してください。
:::answer
60は合格、59はもう一度練習です。境界そのものと、そのすぐ隣を試すと`>`と`>=`の取り違えを見つけやすくなります。
:::

:::exercise 2・ループを手で追う
total=1から始め、[2,3,4]を順に掛けると最後はいくつになりますか。
:::answer
1×2=2、2×3=6、6×4=24。積の初期値は1です。0から始めるとずっと0になります。
:::

:::exercise 3・rangeの終端
`for i in range(4): print(i)`は何を表示しますか。
:::answer
0,1,2,3の四つです。4は含みません。数学で1〜4を足すなら`range(1,5)`を使います。
:::

:::exercise 4・関数を作る
入力xの二乗に1を足して返す関数square_plus_oneを書いてください。
:::answer
`def square_plus_one(x):`の次の行を字下げして`return x ** 2 + 1`と書きます。x=3で10、x=−2で5かを確認します。
:::

:::exercise 5・終了条件
`x=0`の後、`while x<3:`の中で`print(x)`だけを実行しました。なぜ終わらないのでしょう。
:::answer
xが変わらず、条件x<3がずっと真だからです。ループ内に`x = x + 1`を加えるか、`for x in range(3)`を使います。
:::
